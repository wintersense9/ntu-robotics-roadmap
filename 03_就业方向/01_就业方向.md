# 就业方向

本页说明这套课程对应的岗位、每个岗位需要的能力、招聘中的常见要求，以及与课程内容的对应关系。薪资与招聘时间随市场变化，仅作参考。

---

## 1. 岗位分类

机器人相关岗位按工作内容大致分为以下几类，前四类与本课程体系直接对应。

| 岗位 | 主要工作 | 与本体系的关系 |
|---|---|---|
| 感知算法工程师 | 2D/3D 检测、分割、6D 位姿估计、深度估计 | 视觉几何、EECS498 |
| SLAM / 定位算法工程师 | 视觉或激光 SLAM、VIO、多传感器融合、标定 | MRS I/II、Vision Algorithms、VNAV |
| 规划控制工程师 | 路径规划、轨迹优化、MPC、运动控制 | Convex Optimization、Underactuated |
| 机器人软件工程师 | ROS 2 系统、中间件、实时性、部署 | Modern C++、项目课、工具链 |
| 机械臂应用工程师 | 运动规划、抓取、力控、手眼标定 | Photogrammetry、Underactuated |
| 自动驾驶感知 / 定位 / 规划 | 车载感知、高精定位、行为规划 | 全部感知与导航课程 |
| 无人机 / 具身智能 | 视觉导航、VIO、操作学习 | 视觉导航 + 需补强化学习 |

## 3. 招聘要求中的常见关键词

招聘描述（JD）中反复出现的技能，按出现频率整理。

### 几乎所有岗位都会要求

- C++（11/14/17）与 Python
- Linux 开发环境、Git
- 数据结构与算法基础
- 至少一个完整项目，能讲清设计与结果

### 感知与 SLAM 岗位

- OpenCV、Eigen、PCL 或 Open3D
- 多视图几何：相机模型、标定、极几何、BA
- 优化库：Ceres、g2o、GTSAM
- SLAM 框架：ORB-SLAM3、VINS、LIO-SAM、Cartographer（至少读过源码或复现过）
- 传感器：双目、RGB-D、LiDAR、IMU 的模型与标定
- 工程能力：实时性、多线程、内存与计算优化
- 加分：CUDA、TensorRT、嵌入式部署

### 规划控制岗位

- 路径规划：A*、Dijkstra、RRT/RRT*、Hybrid A*
- 轨迹优化：QP、MPC、直接配点
- 控制：PID、LQR、状态空间、系统辨识
- 工具：CasADi、OSQP、Drake、ACADO
- 加分：ROS 2 Navigation2 使用经验、强化学习控制

### 深度学习岗位

- PyTorch、模型训练与调参、数据 pipeline
- 检测/分割网络结构（YOLO、Mask R-CNN、DETR）
- 部署：ONNX、TensorRT、量化
- 加分：顶会论文、Kaggle 或竞赛成绩

## 4. 面试常见内容

### 通用（各岗位）

1. C++：指针与引用、虚函数与虚表、内存布局、STL 容器复杂度、移动语义、多线程同步
2. 算法题：手写快排/堆/二叉树遍历、动态规划、图搜索
3. 项目追问：为什么用这个方法、精度多少、失败场景、如果重做会改什么

### 视觉与几何

1. 推导极约束，说明 E 与 F 的区别与自由度
2. PnP 的 DLT 解法与 RANSAC 流程
3. 相机标定的原理与重投影误差
4. BA 的目标函数、雅可比与稀疏性
5. 手写 ICP 或光流迭代

### SLAM

1. EKF 与图优化的区别与适用场景
2. 位姿图优化的误差函数与求解
3. 回环检测的做法与误匹配处理
4. VIO 中 IMU 预积分的作用
5. 坐标系与变换：世界系、机体系、相机系之间的转换
6. 系统漂移的来源与评估指标（ATE、RPE）

### 规划控制

1. A* 与 RRT 的适用场景
2. MPC 的滚动优化框架与终端约束
3. LQR 的 Q/R 矩阵含义
4. 欠驱动系统的控制思路

### 深度学习

1. 反向传播手推
2. BN 的训练与推理差异
3. 检测网络的 anchor 机制与损失设计
4. 训练不收敛的排查流程

## 5. 行业与公司类型

### 中国

- 自动驾驶：华为车 BU、Momenta、地平线、小马智行、文远知行，以及各车企智驾团队
- 机器人本体：宇树、云深处、优必选、大疆、傅利叶
- 工业与物流：埃斯顿、新松、极智嘉、海康机器人
- 互联网与研究院：各公司机器人实验室、之江实验室、上海 AI Lab

### 新加坡

- 研究机构：A*STAR（I2R、SIMTech）、DSTA
- 工程与国防：ST Engineering
- 外企研发中心：Continental、Bosch、Dyson
- 本地机器人初创与物流自动化公司

### 学术路径

SLAM、三维视觉、机器人学习方向的博士申请通常要求顶会论文（ICRA、IROS、CVPR、ICCV、CoRL）与完整的研究项目经历。本体系提供基础，论文产出需要通过 Independent Study 或实验室实习获得。

## 8. 本体系不覆盖的方向

以下岗位需要额外准备：

- 嵌入式与固件：MCU、RTOS、电机 FOC、通信协议
- 强化学习与机器人学习：PPO、SAC、模仿学习、sim-to-real
- 大模型与 VLA：多模态模型、策略学习
- 机械结构设计：CAD、加工、装配

投递这些方向时，本体系的课程可作为背景，但不足以覆盖岗位的技术要求。
