## 2. 系统与基础

| 工具 | 建议 | 说明 |
|---|---|---|
| Ubuntu | 22.04 LTS（ROS 2 Humble）或 24.04（Jazzy） | 机器人开发的主要平台 |
| WSL2 | 备选 | 不支持 USB 设备与 RealSense，串口配置受限 |

| Git | 必需 | 作业版本管理 |
| VS Code | 主要编辑器 | C++、Python、Remote-SSH |

硬件参考：16 GB 内存与集成显卡可完成 T1–T4 约 90% 的内容。EECS498 作业需要 6–8 GB 显存，显存不足时使用 Colab 或云 GPU。

## 7. 环境搭建

```bash
# 1. 基础
sudo apt update && sudo apt install -y build-essential cmake git python3-pip

# 2. Python
conda create -n robot python=3.10 -y && conda activate robot
pip install numpy scipy matplotlib opencv-python open3d jupyter evo

# 3. C++ 数值与视觉
sudo apt install -y libeigen3-dev libopencv-dev libceres-dev

# 4. ROS 2（按发行版替换 humble）
sudo apt install -y ros-humble-desktop
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc

# 5. 优化与因子图
pip install gtsam cvxpy casadi

# 6. 深度学习
pip install torch torchvision tensorboard

# 7. 验证
python -c "import cv2, numpy, torch; print(cv2.__version__, torch.__version__)"
ros2 run demo_nodes_cpp talker
```

## 8. 常见问题

| 问题 | 处理方式 |
|---|---|
| ROS 2 与 conda Python 冲突 | 使用系统 Python 运行 ROS，或统一放入 Docker |
| CUDA 版本不匹配 | 按 PyTorch 官网给出的版本组合安装 |
| OpenCV 的 C++ 与 Python 版本混用 | C++ 使用系统包，Python 使用 pip 包 |
| Eigen 头文件引用错误 | `#include <Eigen/Dense>` 配合 CMake `find_package(Eigen3)` |
| GTSAM Python 安装失败 | 先安装 Boost，或使用 conda-forge |
| Gazebo 黑屏 | 检查显卡驱动，用 `LIBGL_ALWAYS_SOFTWARE=1` 测试 |
| 点云可视化卡顿 | 先降采样再显示 |
