## 2. 系统与基础

| 工具 | 建议 | 说明 |
|---|---|---|
| Ubuntu | 22.04 LTS（ROS 2 Humble）/ 24.04（Jazzy） | 机器人开发事实标准 |
| WSL2 | 备选 | 无 USB 设备、无 RealSense、串口有坑 |

| VS Code | 主力 | C++ + Python + Remote-SSH |

**最低硬件**：16 GB 内存 + 集显笔记本可完成 T1–T4 的 90%。训 EECS498 作业需要一张 6–8 GB 显存的卡，没有就用 Colab / 云 GPU。

## 7. 环境搭建顺序（一次到位版）

```bash
# 1. 基础
sudo apt update && sudo apt install -y build-essential cmake git python3-pip

# 2. Python
conda create -n robot python=3.10 -y && conda activate robot
pip install numpy scipy matplotlib opencv-python open3d jupyter evo

# 3. C++ 数值与视觉
sudo apt install -y libeigen3-dev libopencv-dev libceres-dev

# 4. ROS 2（按发行版替换 humble）
sudo apt install -y ros-humble-desktop
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc

# 5. 优化与因子图
pip install gtsam cvxpy casadi

# 6. 深度学习
pip install torch torchvision tensorboard

# 7. 验证
python -c "import cv2, numpy, torch; print(cv2.__version__, torch.__version__)"
ros2 run demo_nodes_cpp talker
```

## 8. 常见坑速查

| 问题 | 解决 |
|---|---|
| ROS 2 与 conda Python 冲突 | 用系统 Python 跑 ROS，或全放 Docker |
| CUDA 版本不匹配 | 按 PyTorch 官网给的组合装 |
| OpenCV 的 C++ 与 Python 版本混用 | 只用一个（C++ 用系统包，Python 用 pip） |
| Eigen 用错头文件 | `#include <Eigen/Dense>` + CMake `find_package(Eigen3)` |
| GTSAM Python 装不上 | 先装 Boost，或用 conda-forge |
| Gazebo 黑屏 | 检查显卡驱动，测试 `LIBGL_ALWAYS_SOFTWARE=1` |
| 点云可视化很卡 | 降采样后再显示，别直接显示百万点 |
