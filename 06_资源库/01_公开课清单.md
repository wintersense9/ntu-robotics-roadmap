## 8. 学习顺序建议

```
数学 + 编程（1–2 月）
    → Modern Robotics（1 月）
    → CS231n 或 EECS498（2 月）
    → Mobile Robotics + ROS 2（1.5 月）
    → CS285（2 月）
    → 方向专精课（2–3 月）
```

**不要同时开三门**：每门课都有作业，作业才是真正学到东西的地方。

## 9. 免费证书/学分说明

这些公开课大多不发学位证书，部分（如 edX、Coursera）可付费拿证书。对 NTU 申请而言，**证书价值远低于项目作品**，不要为了刷证书而学习。
