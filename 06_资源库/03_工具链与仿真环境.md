# 工具链与仿真环境

## 1. 操作系统与基础环境

| 工具 | 版本建议 | 说明 |
|---|---|---|
| Ubuntu | 22.04 LTS（ROS 2 Humble）或 24.04（Jazzy） | 机器人开发事实标准 |
| Windows + WSL2 | WSLg | 没装双系统时的折中，ROS 2 可用 |
| Docker | 最新 | 环境隔离，推荐每个项目一个镜像 |
| Git + GitHub | — | 版本管理与作品集 |
| VS Code | 最新 | C++/Python 主力 IDE |
| conda / uv | — | Python 环境（uv 更快） |

**建议**：双系统 Ubuntu + Windows，或 Ubuntu 单系统 + 云 Windows。WSL2 在 USB 设备、RealSense、串口上有坑。

## 3. 仿真器

| 仿真器 | 强项 | 弱项 | 适用 |
|---|---|---|---|
| **Gazebo (Ignition/GZ)** | ROS 集成好、免费 | 渲染差、接触不稳定 | 移动机器人、教学 |
| **MuJoCo** | 接触动力学精确、速度快 | 渲染一般、场景资产少 | 强化学习、操作、腿足 |
| **Isaac Sim / Isaac Lab** | GPU 并行、渲染真实、RL 生态 | 吃显存、上手陡 | 大规模 RL、sim-to-real |
| **PyBullet** | 轻量、Python 友好 | 维护放缓 | 快速原型 |
| **CoppeliaSim** | 图形化、教学友好 | 性能一般 | 教学演示 |
| **Genesis** | 新、快、统一物理 | 生态新 | 前沿实验 |
| **Habitat** | 室内导航、AI 评测 | 偏视觉导航 | 具身 AI 研究 |

### 推荐组合
- 入门：Gazebo + ROS 2
- RL/操作：MuJoCo + mujoco_menagerie
- 大规模训练：Isaac Lab
- 快速验证：PyBullet

## 8. 推荐环境搭建顺序

```bash
# 1. 系统
Ubuntu 22.04 + 中文输入法 + VS Code

# 2. Python
安装 miniconda → conda create -n robot python=3.10
pip install torch torchvision numpy scipy opencv-python open3d

# 3. ROS 2
sudo apt install ros-humble-desktop
source /opt/ros/humble/setup.bash

# 4. 仿真
sudo apt install ros-humble-gazebo-ros-pkgs
pip install mujoco

# 5. 验证
ros2 run demo_nodes_cpp talker
```

## 9. 常见环境坑

| 问题 | 解决 |
|---|---|
| ROS 2 与 conda Python 冲突 | 用 `--system-site-packages` 或在 Docker 里跑 |
| CUDA 版本不匹配 | 按 PyTorch 官网选对应 cu 版本 |
| RealSense 在 WSL 不识别 | 换双系统 |
| Gazebo 黑屏 | 检查显卡驱动，换 `LIBGL_ALWAYS_SOFTWARE=1` 测试 |
| MuJoCo 渲染无窗口 | 用 `MUJOCO_GL=egl` 做离屏渲染 |
| 串口权限 | `sudo usermod -aG dialout $USER` |
| Docker 里用 GPU | 安装 nvidia-container-toolkit |
