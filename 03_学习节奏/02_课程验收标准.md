# 课程验收标准

"看完视频"不等于"学会"。下面给每门课一个**可观察的通过条件**——能全部做到才算这门课过关，做不到就说明只是"看过"。

---

## 1. 基础层

| 课程 | 必须能做到 | 加分项 |
|---|---|---|
| 18.06 线代 | 手算最小二乘；解释正交矩阵与旋转矩阵关系；用 SVD 解释 DLT | 手算 3D 点云 PCA 主轴 |
| 微积分 | 手推高斯牛顿更新式；解释雅可比在 EKF 中的作用 | 推一遍 LM 的阻尼项来源 |
| PyTorch 入门 | 不用 `nn.Sequential`，手写一个训练循环训 MNIST >97% | 手写 DataLoader |
| Modern C++ | 用 Eigen 写"读点云→位姿变换→投影像素"；能改 CMake 加目标 | 用 valgrind/perf 找一次热点 |

---

## 2. 几何与重建层

| 课程 | 必须能做到 | 加分项 |
|---|---|---|
| Photogrammetry I | 标定棋盘格，重投影误差 < 0.5 px；从两图恢复位姿并画点云 | 手写八点法而不是调 `findEssentialMat` |
| Photogrammetry II | 跑通完整 SfM（特征→匹配→BA→稠密），并能解释每步 | 自己实现 BA 并与 Ceres 结果对齐 |
| Multiview Geometry | 独立推出极约束；手写 LK 光流迭代式 | 推三焦点张量（了解即可） |
| 3D Scanning | 实现 ICP 并用真实点云验证收敛；跑通 TSDF 重建 | 做一次非刚性配准 |

**统一的判定方法**：拿一个公开数据集（KITTI / TUM RGB-D / ETH3D），把你的结果和 ground truth 比，算误差。**没有数字的"跑通了"不算通过。**

## 3. SLAM 与导航层

| 课程 | 必须能做到 | 加分项 |
|---|---|---|
| MRS I | 写出 EKF 五公式并实现；粒子滤波定位收敛；占据栅格建图 | 实现 UKF 并对比 EKF |
| MRS II | 自己实现位姿图 Gauss-Newton 求解；跑通带回环的图 SLAM | 用 GTSAM 对比自己实现的精度 |
| Vision Algorithms | 实现特征点法 VO，在 KITTI 上算 ATE；实现直接法并对比 | 加回环 + 局部 BA |
| TUM 实践课 | 独立完成"数据→位姿→轨迹→误差"全链路，并写失败分析 | 在真实机器人/视频上跑 |
| MIT VNAV | 用 GTSAM 写位姿图 SLAM；做外点鲁棒性实验 | 用 ISAM2 观察增量加速 |

**共同标准**：能画出系统的框图（前端/后端/回环），并指出**误差最大的来源**。

## 5. 三张"毕业证"（整体验收）

学完 21 个月，应该能拿出这三个东西。拿不出说明有课没学透：

1. **一个可复现的 SLAM/VO 系统**
   - 输入：公开数据集或自己拍的视频
   - 输出：轨迹 + 地图 + 与 GT 的误差曲线
   - 能讲清架构和失败场景

2. **一个能动的控制 demo**
   - cart-pole 平衡 / 四旋翼轨迹跟踪 / 机械臂到点
   - 有仿真，最好有真机

3. **一份能读论文的能力证明**
   - 任选一篇 ICRA/IROS/CoRL 的感知或导航论文，读完能讲清：问题定义、方法、实验、局限
   - 最好能复现其中一张图

## 6. 自检：什么时候说明你在"假学"

| 症状 | 说明什么 | 怎么改 |
|---|---|---|
| 视频看完 2 倍速，但作业没做 | 只建立了"眼熟" | 停新课，回头做作业 |
| 能调 OpenCV，但推不出公式 | 缺几何/线代 | 回补手推部分 |
| 代码能跑，但说不清为什么 | 缺系统理解 | 画框图 + 写失败分析 |
| 同时开 3 门课 | 每门都半途 | 砍到 1 门主课 |
| 收藏了很多资料，没打开过 | 收集代替学习 | 只留本仓库这一份 |
