# 课程验收标准

本页为各门课给出可观察的完成条件，用于判断课程是否达到掌握程度，而非是否观看完毕。

---

## 1. 基础层

| 课程 | 完成条件 | 进阶项 |
|---|---|---|
| 18.06 线代 | 手算最小二乘；说明正交矩阵与旋转矩阵的关系；用 SVD 解释 DLT | 手算三维点云的 PCA 主轴 |
| 微积分 | 手推高斯牛顿更新式；说明雅可比在 EKF 中的作用 | 推导 LM 阻尼项的来源 |
| PyTorch 入门 | 不使用 `nn.Sequential`，手写训练循环，MNIST 准确率 >97% | 手写 DataLoader |
| Modern C++ | 用 Eigen 实现"读点云 → 位姿变换 → 投影"；能为 CMake 工程增加目标 | 用 perf 或 valgrind 定位一处性能热点 |

## 2. 几何与重建层

| 课程 | 完成条件 | 进阶项 |
|---|---|---|
| Photogrammetry I | 棋盘格标定重投影误差 < 0.5 px；两视图恢复位姿并输出点云 | 手写八点法 |
| Photogrammetry II | 完成 SfM 全流程（特征、匹配、BA、稠密），并能解释各步骤 | 自行实现 BA 并与 Ceres 结果对比 |
| Multiview Geometry | 独立推导极约束；写出 LK 光流迭代式 | 了解三焦点张量 |
| 3D Scanning | 实现 ICP 并在真实点云上验证收敛；完成 TSDF 重建 | 完成一次非刚性配准 |

统一判定方式：在公开数据集（KITTI、TUM RGB-D、ETH3D）上运行，与 ground truth 比较并给出误差数值。

## 3. SLAM 与导航层

| 课程 | 完成条件 | 进阶项 |
|---|---|---|
| MRS I | 写出并实现 EKF 五公式；粒子滤波定位收敛；完成占据栅格建图 | 实现 UKF 并与 EKF 对比 |

共同要求：能画出前端、后端、回环的系统框图，并指出主要误差来源。

## 5. 整体成果

完成全部课程后，可形成以下三项成果：

1. **可复现的 SLAM/VO 系统**
   - 输入：公开数据集或自采视频
   - 输出：轨迹、地图、与 GT 的误差曲线
   - 可说明系统架构与失效场景

2. **可运行的控制示例**
   - cart-pole 平衡、四旋翼轨迹跟踪或机械臂到点
   - 具备仿真环境，条件允许时包含实机

3. **论文阅读能力**
   - 选取一篇 ICRA/IROS/CoRL 中感知或导航方向的论文，能说明问题定义、方法、实验与局限
   - 条件允许时复现其中一张结果图

## 6. 常见失效模式

| 现象 | 原因 | 处理方式 |
|---|---|---|
| 视频看完全程，作业未完成 | 只形成印象，未形成实现能力 | 暂停新课，补齐作业 |
| 能调用 OpenCV，无法推导公式 | 几何与线代基础不足 | 回补手推内容 |
| 代码可运行，无法解释原理 | 缺少系统层面理解 | 绘制框图并撰写失败分析 |
| 同时进行三门课程 | 各门进度均不完整 | 收敛为一门主课 |
| 收集资料多于实际学习 | 收集替代了学习 | 仅保留本仓库资料 |
