# 视觉导航（VO / VIO / 因子图）

到这一步，你已经会几何（Photogrammetry、MVG）、会滤波与图优化（MRS I/II）。三到四门课开始把这些拼成**一个能跑的导航系统**。

---

## 1. Vision Algorithms for Mobile Robotics

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Zurich / Davide Scaramuzza |
| 页面 | https://rpg.ifi.uzh.ch/teaching.html |
| 学期 | T4 |
| 工作量 | 70–90 小时 |
| 前置 | Photogrammetry I、Modern C++、Python |

### 讲什么

视觉里程计（VO）的全景，是"特征点法 vs 直接法"两条路线的对照课。

| 模块 | 内容 |
|---|---|
| 相机与标定 | 针孔模型、畸变、鱼眼、外参标定 |
| 特征点法 | FAST、ORB、描述子匹配、比率检验、外点剔除 |
| 几何求解 | 2D-2D（E）、3D-2D（PnP）、3D-3D（ICP）、RANSAC |
| 运动估计 | 单应/本质矩阵分解、位姿恢复的四种解与选优 |
| 直接法 | 光流、直接图像对齐、光度误差、金字塔 |
| 关键帧与 BA | 局部 BA、滑窗、边缘化 |
| 回环 | 词袋、位姿图 |
| VIO 入门 | IMU 预积分、视觉惯性融合、紧耦合 vs 松耦合 |
| 前沿 | 事件相机、学习型 VO |

### 作业与产出

- 实现特征点法 VO，在 KITTI 上跑出轨迹并算 ATE
- 实现直接法（LK 光流 + 对齐），对比两者在低纹理场景的表现
- 这是**整个仓库里最"能写进简历"的一门**

### 怎么算学会

- 能说清"特征点法在弱纹理下为什么失效，直接法为什么也会失效"；
- 能手推 PnP 的 DLT 解；
- 能解释为什么 VIO 需要预积分而不是直接用 IMU 读数；
- 能跑通一个开源 VO（如 ORB-SLAM3 单目模式）并讲清它的线程结构。

### 配套

- 代码：ORB-SLAM3、DSO、OpenCV（`solvePnP`、`calcOpticalFlowPyrLK`）
- 书：Szeliski 第 7、8 章；《视觉 SLAM 十四讲》（中文入门友好）
- 论文：DSO (2016)、ORB-SLAM (2015)、VINS-Mono (2017)

## 2. TUM Vision-based Navigation（实践课）

| 项目 | 内容 |
|---|---|
| 学校 | TUM（Cremers 组 / CVG） |
| 页面 | https://cvg.cit.tum.de/teaching/ws2020/visnav_ws2020#lectures |
| 学期 | T4 / T5 |
| 工作量 | 60–120 小时 |
| 前置 | Vision Algorithms、ROS、C++ |

### 讲什么

不是讲课，是**做项目**。典型的题目：用单目/双目/RGB-D 做视觉里程计、做稠密建图、做视觉伺服。

| 阶段 | 内容 |
|---|---|
| 第 1–2 周 | 读论文、定方案、搭 ROS 环境 |
| 第 3–6 周 | 实现前端（特征或直接法） |
| 第 7–10 周 | 后端（BA/位姿图）+ 回环 |
| 第 11–12 周 | 在真实数据（TUM RGB-D / KITTI）上评测 + 写报告 |

### 怎么算学会

- 能独立跑通"数据 → 位姿 → 轨迹 → 误差评估"整条链路；
- 能解释你的系统在哪类场景失败，为什么。

## 3. MIT Visual Navigation for Autonomous Vehicles (VNAV)

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | MIT / Luca Carlone |
| 页面 | https://vnav.mit.edu/ |
| 学期 | T7 |
| 工作量 | 80–100 小时 |
| 前置 | 多视图几何、最小二乘、会 Python/C++ |

### 讲什么

VNAV 是**把导航讲成最优化问题**的一门课，理论密度最高。它和 MRS II 的区别：MRS II 偏工程流程，VNAV 偏"为什么这样做是对的"。

| 模块 | 内容 |
|---|---|
| 刚体变换 | SO(3)/SE(3)、旋转表示（四元数/李代数）、伴随 |
| 3D 几何 | 双目深度、点云、特征与描述子 |
| 状态估计 | 最大似然、MAP、非线性最小二乘 |
| 因子图 | 因子图建模、GTSAM 的 API 与哲学 |
| SLAM | 位姿图优化、稀疏求解、增量式优化（iSAM） |
| 鲁棒性 | 外点、鲁棒核、graduated non-convexity |
| 可认证性 | 凸松弛、certifiable perception（Carlone 组的招牌） |
| 视觉惯性 | VIO 的因子图建模 |
| 规划 | 采样式规划、轨迹优化接口 |

### 作业与产出

- 用 GTSAM 写一个位姿图 SLAM，并做鲁棒性实验（人为注入外点）
- 实现/调用 `gtsam.ISAM2`，观察增量求解的加速

### 怎么算学会

- 能用因子图描述"里程计 + 回环 + 先验"三类因子；
- 能解释 iSAM2 的贝叶斯树在做什么；
- 能说清"为什么位姿图优化能从糟糕初值恢复"。

### 配套

- 代码：GTSAM + 官方 Python 教程、Drake（部分）
- 书：Dellaert & Kaess《Factor Graphs for Robot Perception》
- 论文：Carlone 的 "Past, Present, and Future of Simultaneous Localization and Mapping"

## 4. 三门课的关系

| | Vision Algorithms | TUM 实践课 | MIT VNAV |
|---|---|---|---|
| 性质 | 讲课 + 编程作业 | 纯项目 | 讲课（理论最硬） |
| 核心内容 | VO 前端 | 系统集成 | 后端 + 优化理论 |
| 产出 | 一个 VO 实现 | 一个导航系统 | 一个因子图 SLAM |
| 建议顺序 | 先 | 中 | 后 |

**如果时间只够两门**：Vision Algorithms + VNAV。前者给你能跑的代码，后者给你面试和读论文需要的理论。
