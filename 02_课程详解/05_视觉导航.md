# 视觉导航（VO / VIO / 因子图）

本组课程将几何、滤波与图优化内容组合为可运行的导航系统，覆盖视觉里程计、系统集成与基于因子图的后端优化。

---

## 1. Vision Algorithms for Mobile Robotics

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Zurich / Davide Scaramuzza |
| 页面 | https://rpg.ifi.uzh.ch/teaching.html |
| 阶段 | T4 |
| 工作量 | 70–90 小时 |
| 前置 | Photogrammetry I、Modern C++、Python |

### 内容

视觉里程计（VO）的整体框架，以特征点法与直接法的对照为主线。

| 模块 | 内容 |
|---|---|
| 相机与标定 | 针孔模型、畸变、鱼眼、外参标定 |
| 特征点法 | FAST、ORB、描述子匹配、比率检验、外点剔除 |
| 几何求解 | 2D-2D（E）、3D-2D（PnP）、3D-3D（ICP）、RANSAC |
| 运动估计 | 单应/本质矩阵分解、位姿恢复的四种解与选优 |
| 直接法 | 光流、直接图像对齐、光度误差、金字塔 |
| 关键帧与 BA | 局部 BA、滑窗、边缘化 |
| 回环 | 词袋、位姿图 |
| VIO 入门 | IMU 预积分、视觉惯性融合、紧耦合与松耦合 |
| 前沿 | 事件相机、学习型 VO |

### 作业与产出

- 实现特征点法 VO，在 KITTI 上输出轨迹并计算 ATE
- 实现直接法（LK 光流与图像对齐），与特征点法在低纹理场景下对比

### 能力目标

- 能说明特征点法与直接法在弱纹理条件下的失效原因
- 能手推 PnP 的 DLT 解
- 能说明 VIO 使用预积分而非直接 IMU 读数的原因
- 能运行开源 VO（如 ORB-SLAM3 单目模式），说明其线程结构

### 参考

- 代码：ORB-SLAM3、DSO、OpenCV（`solvePnP`、`calcOpticalFlowPyrLK`）
- 书：Szeliski 第 7、8 章；《视觉 SLAM 十四讲》
- 论文：DSO (2016)、ORB-SLAM (2015)、VINS-Mono (2017)

### 内容

| 阶段 | 内容 |
|---|---|

- 能独立完成"数据 → 位姿 → 轨迹 → 误差评估"的完整链路
- 能说明所实现系统在特定场景下的失效原因

## 3. MIT Visual Navigation for Autonomous Vehicles (VNAV)

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | MIT / Luca Carlone |
| 页面 | https://vnav.mit.edu/ |
| 阶段 | T7 |
| 工作量 | 80–100 小时 |
| 前置 | 多视图几何、最小二乘、Python 或 C++ |

### 内容

将导航问题表述为最优化问题，理论密度高于 MRS II。MRS II 侧重工程流程，VNAV 侧重方法的正确性论证。

| 模块 | 内容 |
|---|---|
| 刚体变换 | SO(3)/SE(3)、旋转表示（四元数、李代数）、伴随 |
| 3D 几何 | 双目深度、点云、特征与描述子 |
| 状态估计 | 最大似然、MAP、非线性最小二乘 |
| 因子图 | 因子图建模、GTSAM 的 API 与设计思路 |
| SLAM | 位姿图优化、稀疏求解、增量式优化（iSAM） |
| 鲁棒性 | 外点、鲁棒核、graduated non-convexity |
| 可认证性 | 凸松弛、certifiable perception |
| 视觉惯性 | VIO 的因子图建模 |
| 规划 | 采样式规划、轨迹优化接口 |

### 作业与产出

- 用 GTSAM 实现位姿图 SLAM，并注入外点进行鲁棒性实验
- 调用 `gtsam.ISAM2`，对比增量求解与批量求解的耗时

### 能力目标

- 能用因子图描述里程计因子、回环因子与先验因子
- 能说明 iSAM2 中贝叶斯树的作用
- 能说明位姿图优化从较差初值恢复的原因

### 参考

- 代码：GTSAM 与官方 Python 教程、Drake（部分）
- 书：Dellaert & Kaess《Factor Graphs for Robot Perception》
- 论文：Carlone, "Past, Present, and Future of Simultaneous Localization and Mapping"

## 4. 三门课的分工

| | Vision Algorithms | TUM 实践课 | MIT VNAV |
|---|---|---|---|
| 性质 | 讲课与编程作业 | 纯项目 | 讲课，理论密度最高 |
| 核心内容 | VO 前端 | 系统集成 | 后端与优化理论 |
| 产出 | VO 实现 | 导航系统 | 因子图 SLAM |
| 顺序 | 先 | 中 | 后 |

时间有限时，Vision Algorithms 与 VNAV 的组合覆盖可运行的代码与系统理论两部分。
