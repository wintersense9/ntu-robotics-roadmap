# 视觉几何与三维重建

这一组是"机器人怎么看见世界"的数学核心：**相机怎么成像 → 两张图怎么恢复三维 → 多张图怎么重建整个场景 → 扫描仪怎么拿到点云**。三门课层层递进，是整个仓库最不能跳的部分。

---

## 1. Photogrammetry I

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Bonn / Cyrill Stachniss |
| 页面 | https://www.ipb.uni-bonn.de/photo12-2021/ |
| 学期 | T1 |
| 工作量 | 50–70 小时 |
| 前置 | 线代、Modern C++ 或 Python |

### 讲什么

摄影测量 = 从照片里量出几何。它和计算机视觉是同一个问题的两个流派，摄影测量的表述更工程化。

| 模块 | 内容 |
|---|---|
| 相机模型 | 针孔模型、内参（f, cx, cy）、外参（R, t）、畸变（径向/切向）、齐次坐标 |
| 投影几何 | 单应矩阵、消失点、射影/仿射/欧氏变换的层级 |
| 标定 | 张正友标定法、棋盘格、重投影误差 |
| 特征 | Harris、SIFT、描述子匹配、比值检验 |
| 两视图 | 极几何、本质矩阵 E、基础矩阵 F、八点法、RANSAC |
| 三角化 | 线性三角化、重投影误差最小化 |
| SfM 入门 | 增量式重建流程、BA 概念 |

### 作业与产出

- 相机标定：自己拍棋盘格，输出内参与重投影误差（要求 < 0.5 px）
- 两视图重建：匹配 → E/F → 三角化 → 画出点云
- 作业都是**编程 + 手推**混合，手推部分不能跳

### 怎么算学会

- 给你两张图，你能说清"为什么这 8 个点是外点"；
- 能解释 E 和 F 的自由度分别是 5 和 7；
- 能写出 `x₂ᵀ F x₁ = 0` 并说明每一项的含义。

### 配套

- 书：《Multiple View Geometry》Hartley & Zisserman（第 1–9 章，这是圣经）
- 代码：OpenCV `calibrateCamera`、`findEssentialMat`、`recoverPose`

### 坑

- 畸变模型别自己乱调，先用 OpenCV 默认 5 参数。
- RANSAC 阈值和图像分辨率强相关，换数据集要重调。
- 纯旋转场景下 E 退化成无穷多解，这是几何问题不是代码 bug。

## 2. Photogrammetry II

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Bonn / Cyrill Stachniss |
| 页面 | https://www.ipb.uni-bonn.de/photo12-2021/ |
| 学期 | T2 |
| 工作量 | 50–70 小时 |
| 前置 | Photogrammetry I |

### 讲什么

从"两张图"走到"整个场景"。

| 模块 | 内容 |
|---|---|
| 稠密匹配 | 立体校正、视差图、半全局匹配（SGM） |
| 多视图立体 | 深度图融合、TSDF、泊松重建、纹理映射 |
| 光束法平差 | 重投影误差、雅可比、稀疏性、Schur 补、LM 算法 |
| LiDAR 摄影测量 | 点云与影像配准、点云配准基础 |
| 增量式 SfM | 初始化、图像注册、三角化、BA、outlier 处理 |

### 作业与产出

- 实现一个**完整 SfM pipeline**：输入一组图像，输出相机位姿 + 稀疏点云
- 或：实现 BA，把手算的雅可比验证到数值雅可比

### 怎么算学会

- 能用 COLMAP 重建一个房间，并解释它的每一步在做什么；
- 能说清 BA 的稀疏结构为什么能用 Schur 补加速；
- 知道什么场景会让 SfM 失败（弱纹理、重复纹理、纯旋转）。

### 配套

- 代码：COLMAP（读它的 pipeline 文档）、Ceres Solver（BA 实现）
- 书：Szeliski《Computer Vision: Algorithms and Applications》第 7、11 章

## 3. Multiview Geometry

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | TUM / Daniel Cremers |
| 页面 | https://cvg.cit.tum.de/teaching/ss2019/mvg2019 |
| 学期 | T3 |
| 工作量 | 50–70 小时 |
| 前置 | Photogrammetry I（或同等几何基础）、线代 |

### 讲什么

Cremers 的版本比 Bonn 更偏**数学严格性**，很多结论是课堂上现场推的。和 Photogrammetry 的关系是"同一个骨架，换一套更硬的推导"。

| 模块 | 内容 |
|---|---|
| 射影几何 | 二维/三维射影空间、对偶、圆锥曲线 |
| 相机与标定 | 投影矩阵分解、绝对二次曲线 |
| 两视图 | 极几何、E/F 的推导、三角化与最优三角化 |
| 三视图 | 三焦点张量（了解即可） |
| 双目立体 | 视差、深度、立体匹配、SGM |
| 光流 | Lucas-Kanade、Horn-Schunck、变分光流 |
| SfM | 分解法、增量式、全局式 |
| 稠密重建 | 变分方法、多视图立体 |

### 作业与产出

- 手推题为主 + 编程题：极几何估计、光流实现

### 怎么算学会

- 能独立推出极约束，并解释极线为什么是 1 维；
- 能手写 LK 光流的迭代式；
- 能对比"直接法 vs 特征点法"的取舍。

### 配套

- 书：Hartley & Zisserman（同一本，二刷，这次读推导）
- 补充：Cremers 的 lecture notes

## 4. 3D Scanning and Motion Capture

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | TUM / Matthias Niessner |
| 页面 | https://www.cs.cit.tum.de/cg/teaching/winter-term-2122/3d-scanning-motion-capture/ |
| 学期 | T6 |
| 工作量 | 60–80 小时 |
| 前置 | 几何基础、C++/Python |

### 讲什么

从"重建静态场景"走到"重建动态的人和物体"，是三维视觉最工程化的一门。

| 模块 | 内容 |
|---|---|
| 深度传感 | 结构光、ToF、双目深度相机原理与误差 |
| 点云处理 | 滤波、法向估计、特征、分割 |
| 配准 | ICP、point-to-plane、全局配准（FPFH + RANSAC） |
| 非刚性配准 | 人体形变、embedded deformation |
| 表面重建 | 泊松重建、TSDF/volumetric fusion、mesh 简化 |
| 动作捕捉 | 多相机标定、marker-based vs markerless、SMPL 人体模型 |
| 实时重建 | KinectFusion 类系统、动态场景 |

### 作业与产出

- ICP 实现并用真实点云验证收敛
- 用深度相机（或公开数据集）做一次实时 TSDF 重建

### 怎么算学会

- 能解释 ICP 为什么会陷入局部极小，怎么用初值/多尺度解决；
- 能说清 TSDF 的截断距离对重建质量的影响；
- 能跑通一个 KinectFusion 风格的 demo。

### 配套

- 代码：Open3D（点云 + 配准 + 重建一条龙）、OpenCV
- 论文：KinectFusion (2011)、DynamicFusion (2015)

## 5. 这三门的先后必要性

| 顺序 | 为什么不能反 |
|---|---|
| Photogrammetry I → II | II 的 BA 依赖 I 的投影模型和 E/F |
| Photogrammetry I → Multiview Geometry | MVG 是同一套内容的严格版，是"二刷 + 加深" |
| 几何三门 → 3D Scanning | 扫描的配准和重建建立在多视图几何之上 |

**如果只能学一门**：Photogrammetry I（覆盖率最高）。**如果能学两门**：加 Photogrammetry II（得到完整 SfM）。
