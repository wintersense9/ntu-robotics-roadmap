# 视觉几何与三维重建

本组课程处理从图像恢复几何结构的完整流程：相机成像模型、两视图三维恢复、多视图场景重建、扫描点云获取。三门课依次递进，是后续视觉导航课程的直接基础。

---

## 1. Photogrammetry I

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Bonn / Cyrill Stachniss |
| 页面 | https://www.ipb.uni-bonn.de/photo12-2021/ |
| 阶段 | T1 |
| 工作量 | 50–70 小时 |
| 前置 | 线代、Modern C++ 或 Python |

### 内容

摄影测量研究如何从照片测量几何量，与计算机视觉处理同一问题，表述偏工程化。

| 模块 | 内容 |
|---|---|
| 相机模型 | 针孔模型、内参（f, cx, cy）、外参（R, t）、畸变（径向/切向）、齐次坐标 |
| 投影几何 | 单应矩阵、消失点、射影/仿射/欧氏变换的层级 |
| 标定 | 张正友标定法、棋盘格、重投影误差 |
| 特征 | Harris、SIFT、描述子匹配、比值检验 |
| 两视图 | 极几何、本质矩阵 E、基础矩阵 F、八点法、RANSAC |
| 三角化 | 线性三角化、重投影误差最小化 |
| SfM 入门 | 增量式重建流程、BA 概念 |

### 作业与产出

- 相机标定：拍摄棋盘格，输出内参与重投影误差（目标 < 0.5 px）
- 两视图重建：匹配 → E/F → 三角化 → 输出点云
- 作业包含编程与手推两部分

### 能力目标

- 给定两张图像，能判断匹配点中的外点及其原因
- 能说明 E 与 F 的自由度分别为 5 和 7
- 能写出 `x₂ᵀ F x₁ = 0` 并解释各项含义

### 参考

- 书：《Multiple View Geometry》Hartley & Zisserman（第 1–9 章）
- 代码：OpenCV `calibrateCamera`、`findEssentialMat`、`recoverPose`

### 注意事项

- 畸变模型使用 OpenCV 默认的 5 参数形式
- RANSAC 阈值与图像分辨率相关，更换数据集后需重新设置
- 纯旋转场景下 E 退化，属于几何约束而非实现错误

## 2. Photogrammetry II

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Bonn / Cyrill Stachniss |
| 页面 | https://www.ipb.uni-bonn.de/photo12-2021/ |
| 阶段 | T2 |
| 工作量 | 50–70 小时 |
| 前置 | Photogrammetry I |

### 内容

从两视图扩展到完整场景重建。

| 模块 | 内容 |
|---|---|
| 稠密匹配 | 立体校正、视差图、半全局匹配（SGM） |
| 多视图立体 | 深度图融合、TSDF、泊松重建、纹理映射 |
| 光束法平差 | 重投影误差、雅可比、稀疏性、Schur 补、LM 算法 |
| LiDAR 摄影测量 | 点云与影像配准、点云配准基础 |
| 增量式 SfM | 初始化、图像注册、三角化、BA、外点处理 |

### 作业与产出

- 实现完整 SfM pipeline：输入图像序列，输出相机位姿与稀疏点云
- 或实现 BA，并用数值雅可比验证手推结果

### 能力目标

- 能用 COLMAP 重建场景，并说明各步骤作用
- 能说明 BA 的稀疏结构与 Schur 补的加速原理
- 能判断 SfM 的失效条件（弱纹理、重复纹理、纯旋转）

### 参考

- 代码：COLMAP（pipeline 文档）、Ceres Solver（BA 实现）
- 书：Szeliski《Computer Vision: Algorithms and Applications》第 7、11 章

## 3. Multiview Geometry

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | TUM / Daniel Cremers |
| 页面 | https://cvg.cit.tum.de/teaching/ss2019/mvg2019 |
| 阶段 | T3 |
| 工作量 | 50–70 小时 |
| 前置 | Photogrammetry I 或同等几何基础、线代 |

### 内容

与 Photogrammetry 覆盖同一知识框架，推导更完整，多数结论在课堂上直接给出推导过程。

| 模块 | 内容 |
|---|---|
| 射影几何 | 二维/三维射影空间、对偶、圆锥曲线 |
| 相机与标定 | 投影矩阵分解、绝对二次曲线 |
| 两视图 | 极几何、E/F 推导、三角化与最优三角化 |
| 三视图 | 三焦点张量（了解） |
| 双目立体 | 视差、深度、立体匹配、SGM |
| 光流 | Lucas-Kanade、Horn-Schunck、变分光流 |
| SfM | 分解法、增量式、全局式 |
| 稠密重建 | 变分方法、多视图立体 |

### 作业与产出

以手推题为主，编程题包括极几何估计与光流实现。

### 能力目标

- 能独立推导极约束，并说明极线为一维的原因
- 能写出 LK 光流的迭代式
- 能比较直接法与特征点法的取舍

### 参考

- 书：Hartley & Zisserman（配套推导部分）
- 补充：Cremers 的 lecture notes

## 4. 3D Scanning and Motion Capture

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | TUM / Matthias Niessner |
| 页面 | https://www.cs.cit.tum.de/cg/teaching/winter-term-2122/3d-scanning-motion-capture/ |
| 阶段 | T6 |
| 工作量 | 60–80 小时 |
| 前置 | 几何基础、C++/Python |

### 内容

从静态场景重建扩展到动态人体与物体的重建，工程性较强。

| 模块 | 内容 |
|---|---|
| 深度传感 | 结构光、ToF、双目深度相机的原理与误差 |
| 点云处理 | 滤波、法向估计、特征、分割 |
| 配准 | ICP、point-to-plane、全局配准（FPFH + RANSAC） |
| 非刚性配准 | 人体形变、embedded deformation |
| 表面重建 | 泊松重建、TSDF/volumetric fusion、mesh 简化 |
| 动作捕捉 | 多相机标定、marker-based 与 markerless、SMPL 人体模型 |
| 实时重建 | KinectFusion 类系统、动态场景 |

### 作业与产出

- 实现 ICP，并在真实点云上验证收敛
- 使用深度相机或公开数据集完成一次 TSDF 重建

### 能力目标

- 能解释 ICP 的局部极小问题及初值、多尺度的作用
- 能说明 TSDF 截断距离对重建质量的影响
- 能运行 KinectFusion 风格的实时重建示例

### 参考

- 代码：Open3D（点云、配准、重建）、OpenCV
- 论文：KinectFusion (2011)、DynamicFusion (2015)

## 5. 三门课的先后关系

| 顺序 | 原因 |
|---|---|
| Photogrammetry I → II | II 的 BA 依赖 I 的投影模型与 E/F |
| Photogrammetry I → Multiview Geometry | MVG 为同一内容的严格推导版本 |
| 几何三门 → 3D Scanning | 扫描中的配准与重建以多视图几何为基础 |

覆盖范围最广的是 Photogrammetry I；增加 Photogrammetry II 后可获得完整的 SfM 流程。
