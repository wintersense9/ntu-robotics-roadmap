# 控制与优化

前面的课程解决状态估计与环境建模，本组课程处理运动生成。这两门课也是机械臂、腿足机器人与无人机方向的主要理论来源。

---

## 1. Convex Optimization

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | Stanford / Stephen Boyd（edX 版与 EE364a 讲义） |
| 页面 | https://www.edx.org/course/convex-optimization |
| 学期 | 备选（建议安排在 T5 前后） |
| 工作量 | 70–90 小时 |
| 前置 | 线代、微积分 |

### 内容

最优化是机器人中使用频率最高的数学工具，SLAM 后端、标定、轨迹优化、MPC 与策略学习均归结为最优化问题。

| 模块 | 内容 |
|---|---|
| 凸集与凸函数 | 定义、保凸运算、判定准则 |
| 凸问题 | LP、QP、SOCP、SDP、标准形式 |
| 对偶 | 拉格朗日对偶、强弱对偶、Slater 条件 |
| KKT | 最优性条件、互补松弛 |
| 算法 | 梯度法、牛顿法、内点法、ADMM 入门 |
| 建模 | 工程问题到凸问题的转换 |
| 应用 | 最小二乘、鲁棒估计、稀疏、几何规划 |

### 作业与产出

- 用 CVXPY 建模并求解 5–8 个问题：最小二乘、Lasso、MPC 小例子
- 推导 2–3 个对偶问题

### 掌握标准

- 能用保凸运算逐层判断问题的凸性
- 能写出 KKT 条件，并解释互补松弛的含义
- 能将"轨迹平滑 + 避障"写成 QP 并求解

### 参考

- 书：Boyd《Convex Optimization》（第 1–5 章）
- 工具：CVXPY、OSQP、CasADi

### 注意事项

- 内点法实现部分可在建模熟练后再看
- 凸性判断错误会导致后续全部结论失效，建议逐条核对保凸规则

## 2. Underactuated Robotics

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | MIT / Russ Tedrake |
| 页面 | https://underactuated.csail.mit.edu/index.html |
| 学期 | T7 |
| 工作量 | 80–100 小时 |
| 前置 | 线代、微积分、动力学基础、Python |
| 配套代码 | Drake（https://drake.mit.edu/） |

### 内容

欠驱动指执行器数量少于自由度，双足、四旋翼、机械臂抓取等系统均属此类。课程内容为现代机器人控制的主要理论框架。

| 模块 | 内容 |
|---|---|
| 动力学建模 | 拉格朗日方程、刚体动力学、状态空间形式 |
| 线性系统 | 可控性、可观性、稳定性、LQR |
| 动态规划 | HJB、值迭代、LQR 的 DP 解释 |
| 轨迹优化 | 直接配点、直接打靶、约束、初值敏感性 |
| MPC | 滚动优化、终端约束、实时性 |
| 反馈运动规划 | 局部反馈策略、LQR-Trees |
| 欠驱动实例 | 摆、cart-pole、acrobot、四旋翼、双足 |
| 接触 | 接触建模、混合动力学、抓取 |
| 学习与控制 | policy search、模仿学习的控制视角 |

### 作业与产出

- 用 Drake 实现 cart-pole 的 LQR 平衡
- 用直接配点完成四旋翼或双足的轨迹优化
- 实现 MPC 控制器并在仿真中闭环

### 掌握标准

- 能对简单系统列写拉格朗日方程并线性化
- 能说明 LQR 中 Q/R 矩阵对行为的影响
- 能比较直接配点与直接打靶的数值特性
- 能使用 Drake 的 `MathematicalProgram` 求解轨迹优化

### 参考

- 教材：Tedrake《Underactuated Robotics》（在线）
- 代码：Drake（Python 绑定）、PyBullet（轻量替代）
- 动力学补充：MIT 2.003 或 Craig《机器人学导论》前 6 章

### 注意事项

- 课程难度高于本体系其他课程，适合安排在最后阶段
- 轨迹优化的初值与约束尺度对收敛影响较大，先求解无约束情形
- MPC 以 LQR 为基础，线性系统部分不宜跳过

## 3. 两门课的配置

| 目标 | 必需 | 可选 |
|---|---|---|
| 移动机器人、自动驾驶 | Convex Optimization（MPC 所需） | Underactuated（动力学部分） |
| 机械臂、抓取 | Underactuated（接触与规划部分） | Convex Optimization（轨迹优化） |
| 腿足、无人机 | 两门均需 | — |
| 感知算法岗 | 均非必须 | Convex Optimization（后端优化） |

建议顺序为先 Convex Optimization，后 Underactuated，后者将前者的工具用于动力学问题。
