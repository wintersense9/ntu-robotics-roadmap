# 控制与优化

前面所有课解决"我现在在哪、周围什么样"，这两门解决"我该怎么动"。它们也是机械臂、腿足、无人机方向的分水岭——**只学感知不学控制，你的机器人只能看不能动**。

---

## 1. Convex Optimization

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | Stanford / Stephen Boyd（edX 版 + EE364a 讲义） |
| 页面 | https://www.edx.org/course/convex-optimization |
| 学期 | 备选（建议插在 T5 前后） |
| 工作量 | 70–90 小时 |
| 前置 | 线代、微积分 |

### 讲什么

优化是机器人里出现频率最高的数学工具：SLAM 后端、标定、轨迹优化、MPC、策略学习，全是最优化问题。

| 模块 | 内容 |
|---|---|
| 凸集与凸函数 | 定义、保凸运算、判定准则 |
| 凸问题 | LP / QP / SOCP / SDP、标准形式 |
| 对偶 | 拉格朗日对偶、强弱对偶、Slater 条件 |
| KKT | 最优性条件、互补松弛 |
| 算法 | 梯度/牛顿法、内点法、ADMM 入门 |
| 建模 | 如何把工程问题写成凸问题（最有用的部分） |
| 应用 | 最小二乘、鲁棒估计、稀疏、几何规划 |

### 作业与产出

- 用 CVXPY 建模并求解 5–8 个问题：最小二乘、Lasso、MPC 小例子
- 手推 2–3 个对偶问题

### 怎么算学会

- 能判断一个问题是不是凸的（用保凸运算逐层验证）；
- 能写出 KKT 条件并解释互补松弛的物理含义；
- 能把"轨迹平滑 + 避障"写成一个 QP 并解出来。

### 配套

- 书：Boyd《Convex Optimization》（免费 PDF，第 1–5 章是核心）
- 工具：CVXPY、OSQP、CasADi

### 坑

- 不要一上来读第 11 章内点法实现，先会建模。
- "凸"的判断错了，后面全错；养成逐条检查保凸规则的习惯。

## 2. Underactuated Robotics

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | MIT / Russ Tedrake |
| 页面 | https://underactuated.csail.mit.edu/index.html |
| 学期 | T7 |
| 工作量 | 80–100 小时 |
| 前置 | 线代、微积分、动力学基础、Python |
| 配套代码 | Drake（https://drake.mit.edu/） |

### 讲什么

"欠驱动"= 执行器数量少于自由度，几乎所有真实机器人（双足、四旋翼、机械臂抓取）都是欠驱动的。这门课是**现代机器人控制的正统入口**。

| 模块 | 内容 |
|---|---|
| 动力学建模 | 拉格朗日方程、刚体动力学、状态空间形式 |
| 线性系统 | 可控性、可观性、稳定性、LQR |
| 动态规划 | HJB、值迭代、LQR 的 DP 解释 |
| 轨迹优化 | 直接配点、直接打靶、约束、初值敏感性 |
| MPC | 滚动优化、终端约束、实时性 |
| 反馈运动规划 | 局部反馈策略、LQR-Trees |
| 欠驱动实例 | 摆、cart-pole、acrobot、四旋翼、双足 |
| 接触 | 接触建模、混合动力学、抓取 |
| 学习与控制 | policy search、模仿学习的控制视角 |

### 作业与产出

- 用 Drake 实现 cart-pole 的 LQR 平衡
- 用直接配点做四旋翼/双足的轨迹优化
- 实现一个 MPC 控制器并在仿真里闭环

### 怎么算学会

- 能对一个简单系统列拉格朗日方程并线性化；
- 能解释 LQR 的 Q/R 矩阵怎么影响行为；
- 能说清"直接配点 vs 直接打靶"的取舍与数值病态；
- 能跑通 Drake 的 `MathematicalProgram` 解一个轨迹优化。

### 配套

- 教材：Tedrake 在线书《Underactuated Robotics》（免费，边看视频边读）
- 代码：Drake（Python 绑定）、PyBullet（轻量替代）
- 前置补课：如果动力学没学过，先看 MIT 2.003 或 Craig《机器人学导论》前 6 章

### 坑

- 这门课**难度明显高于其他课**，放在最后学，别在 T2 就去碰。
- 轨迹优化的初值和约束尺度决定成败，先做无约束再加约束。
- 别跳过线性系统部分直接看 MPC，LQR 是 MPC 的基础。

## 3. 两门课怎么配

| 目标 | 必学 | 选学 |
|---|---|---|
| 移动机器人/自动驾驶 | Convex Optimization（MPC 需要） | Underactuated（动力学部分） |
| 机械臂/抓取 | Underactuated（接触/规划） | Convex Optimization（轨迹优化） |
| 腿足/无人机 | 两门都要 | — |
| 感知算法岗 | 都不必须 | Convex Optimization（后端优化会用到） |

**组合建议**：先 Convex Optimization（数学工具），再 Underactuated（把这些工具用在动力学上）。反过来会很难受。
