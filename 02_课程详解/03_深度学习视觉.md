## 1. 讲什么

一门课把"视觉里的深度学习"从 kNN 讲到 3D。它的定位不是"教你调库"，而是**让你能手写反向传播和卷积**。

| 模块 | 内容 | 对应作业 |
|---|---|---|
| 图像分类基础 | kNN、线性分类器、SVM/Softmax 损失、正则化 | A1：手写 kNN / SVM / Softmax |
| 反向传播 | 计算图、链式法则、数值梯度检验 | A1 |
| 神经网络 | 两层网络、激活函数、初始化、批归一化、dropout | A2：手写两层网络与训练循环 |
| 优化 | SGD、Momentum、RMSProp、Adam、学习率调度 | A2 |
| 卷积网络 | 卷积/池化、感受野、经典架构（AlexNet→ResNet）、迁移学习 | A3：手写卷积与 CNN |
| 训练技巧 | 数据增强、超参搜索、过拟合诊断、可视化 | A3 |
| 检测与分割 | R-CNN 家族、YOLO、语义/实例分割、Mask R-CNN | A4 |
| 序列与注意力 | RNN/LSTM、Attention、Transformer、ViT | A4 |
| 生成模型 | VAE、GAN、扩散模型入门 | A5 |
| 自监督与视频 | 对比学习、MAE、视频理解 | A5 |
| 3D 视觉 | 点云网络、NeRF/神经渲染入门 | 期末项目 |

### 和机器人有什么关系

机器人的"语义层"全靠这门课：
- 检测/分割 → 抓取目标、可通行区域
- 位姿估计网络 → 6D grasp pose
- 自监督 → 少标注的真实数据
- NeRF/3DGS → 场景重建与仿真资产

**但这门课不教"怎么把网络接到机器人上"**，那部分在 Vision Algorithms 和 VNAV 里。

## 2. 作业要求（这才是重点）

5 个编程作业，全部要求**从零实现**，不允许用高层 API 糊：

| 作业 | 必须自己写的东西 | 时长 |
|---|---|---|
| A1 | kNN 分类器、SVM/Softmax 损失与梯度、线性分类器训练 | 10–15 h |
| A2 | 两层全连接网络、反向传播、SGD/Adam 从零实现 | 20–25 h |
| A3 | 卷积前向/反向、池化、一个小型 CNN、训练到 CIFAR-10 >70% | 25–30 h |
| A4 | 检测头、注意力模块、RNN/Transformer 单元 | 25–30 h |
| A5 | GAN 训练、自监督预训练 | 20–25 h |
| Final Project | 自选题目，必须复现一篇论文或做一个完整 pipeline | 30–40 h |

> 别抄作业答案。这套作业的价值全在"梯度推错、loss 不降、然后 debug 出来"的过程里。

---

## 3. 怎么算学会

- 能手推两层网络的反向传播，并用数值梯度验证到 1e-7；
- 能解释 BatchNorm 在训练和推理时的行为差异；
- 能自己写一个 ResNet block 并训练到 CIFAR-10 > 93%；
- 能读懂一篇 CVPR 论文的方法部分，说清它的 loss 和网络结构。

## 5. 坑

- **不要跳过 A1/A2 直接看 Transformer**。反向传播的直觉只能靠手写建立。
- 训练不收敛先查三件事：学习率、数据归一化、label 对不对。
- 别一上来就训大模型。CIFAR-10 和 ResNet-18 足够把这门课学透。
- 显卡不够就用 Colab / 云 GPU，这门课不需要 4090。
- 期末项目选"复现"比选"创新"更划算：复现能暴露所有工程细节。
