## 1. 内容

课程覆盖视觉深度学习的完整脉络，重点在实现层面：反向传播与卷积要求手写完成，而非调用高层 API。

| 模块 | 内容 | 对应作业 |
|---|---|---|
| 图像分类基础 | kNN、线性分类器、SVM/Softmax 损失、正则化 | A1：手写 kNN / SVM / Softmax |
| 反向传播 | 计算图、链式法则、数值梯度检验 | A1 |
| 神经网络 | 两层网络、激活函数、初始化、批归一化、dropout | A2：手写两层网络与训练循环 |
| 优化 | SGD、Momentum、RMSProp、Adam、学习率调度 | A2 |
| 卷积网络 | 卷积/池化、感受野、经典架构（AlexNet→ResNet）、迁移学习 | A3：手写卷积与 CNN |
| 训练方法 | 数据增强、超参搜索、过拟合诊断、可视化 | A3 |
| 检测与分割 | R-CNN 家族、YOLO、语义/实例分割、Mask R-CNN | A4 |
| 序列与注意力 | RNN/LSTM、Attention、Transformer、ViT | A4 |
| 生成模型 | VAE、GAN、扩散模型入门 | A5 |
| 自监督与视频 | 对比学习、MAE、视频理解 | A5 |
| 3D 视觉 | 点云网络、NeRF/神经渲染入门 | 期末项目 |

### 与机器人方向的关系

机器人系统的语义层依赖该课程的内容：

- 检测与分割用于确定抓取目标与可通行区域
- 位姿估计网络用于 6D grasp pose
- 自监督方法用于减少真实数据标注
- NeRF/3DGS 用于场景重建与仿真资产

网络与机器人系统的集成不在本课程范围内，相关内容见 Vision Algorithms 与 MIT VNAV。

## 2. 作业

5 个编程作业均要求从零实现，不使用高层 API。

| 作业 | 实现内容 | 时长 |
|---|---|---|
| A1 | kNN 分类器、SVM/Softmax 损失与梯度、线性分类器训练 | 10–15 h |
| A2 | 两层全连接网络、反向传播、SGD/Adam | 20–25 h |
| A3 | 卷积前向/反向、池化、小型 CNN，CIFAR-10 训练准确率 >70% | 25–30 h |
| A4 | 检测头、注意力模块、RNN/Transformer 单元 | 25–30 h |
| A5 | GAN 训练、自监督预训练 | 20–25 h |
| Final Project | 复现论文或完成完整 pipeline | 30–40 h |

作业的主要收获来自梯度推导、loss 不收敛的排查与调试过程。

---

## 3. 能力目标

- 能手推两层网络的反向传播，数值梯度检验误差 < 1e-7
- 能说明 BatchNorm 在训练与推理阶段的差异
- 能实现 ResNet block，CIFAR-10 准确率 > 93%
- 能读懂 CVPR 论文的方法部分，说明其 loss 与网络结构

## 5. 注意事项

- A1、A2 提供的反向传播直觉是后续内容的基础，不宜跳过

- 显存不足时使用 Colab 或云 GPU
- 期末项目选择复现论文，可覆盖更多工程细节
