# 编程与数学基础

本课程体系包含两门前置课（线代、微积分）和一门工具课（Modern C++）。后两类内容贯穿全部后续课程：数学提供推导基础，C++ 提供实现手段。

## 1. Modern C++ for Computer Vision

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Bonn / Cyrill Stachniss |
| 页面 | https://www.ipb.uni-bonn.de/teaching/cpp-2020/ |
| 学期 | T1 |
| 工作量 | 60–80 小时 |
| 前置 | 任一门编程语言基础（Python/Java/Matlab） |

### 内容

课程面向需要编写视觉与机器人程序的学习者，目标为读懂并修改 Eigen、OpenCV、ROS 中的 C++ 代码，不涉及编译器或语言标准实现。

| 模块 | 内容 |
|---|---|
| 编译与构建 | 预处理、编译、链接、头文件、CMake、多文件工程 |
| 语言核心 | 值/引用/指针、const、类与构造析构、继承、虚函数 |
| 现代特性 | 模板、auto、lambda、智能指针、move 语义、STL 容器与算法 |
| 数值库 | Eigen（矩阵、向量、四元数、块操作）、Sophus（李群） |
| 视觉库 | OpenCV 的 Mat、读写、滤波、特征、可视化 |
| 工程化 | 性能分析、多线程、单元测试、Git 协作 |

### 作业与产出

3–5 个小程序：矩阵运算、图像滤波、特征提取与匹配、点云变换。每个作业使用 CMake 组织。

### 掌握标准

- 能使用 Eigen 编写"读点云 → 位姿变换 → 投影到图像"的程序
- 能说明 `std::unique_ptr` 与值语义的适用场景
- 能为现有 CMake 工程增加可执行目标与依赖

### 参考

- 书：《Effective Modern C++》（选读）
- 代码：Eigen 官方 tutorial、OpenCV 官方 tutorial
- 速查：cppreference.com

### 注意事项

- 课程覆盖的语言特性有限，其余内容按需查阅
- 建议使用 CMake 而非 IDE 默认工程结构，后续 ROS 与 OpenCV 均依赖 CMake
- 模板报错信息较长，通常从末行开始阅读

## 2. 18.06 Linear Algebra

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | MIT / Gilbert Strang |
| 页面 | https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/ |
| 学期 | 前置（T1 之前或并行） |
| 工作量 | 30–40 小时 |
| 前置 | 高中代数 |

### 内容

机器人中的位姿表示为 SE(3)，标定转化为最小二乘，SLAM 后端为稀疏线性系统，PCA 依赖 SVD，优化依赖求导与方程求解，均以矩阵形式表达。

必看：消元与 LU、四个基本子空间、正交与投影、最小二乘、特征值与特征向量、对称矩阵与正定、SVD。

可跳过：数值稳定性细节、大规模稀疏求解实现。

### 掌握标准

- 能手算 3×3 的最小二乘问题
- 能说明旋转矩阵正交且行列式为 1 的原因
- 能用 SVD 解释直接线性变换（DLT）求解相机矩阵的原理

### 参考

- 书：《Introduction to Linear Algebra》(Strang)
- 补充：3Blue1Brown《线性代数的本质》，用于建立直观理解

## 3. 微积分

| 项目 | 内容 |
|---|---|
| 资源 | 3Blue1Brown 微积分系列，MIT 18.01（选看） |
| 学期 | 前置 |
| 工作量 | 20–30 小时 |

### 所需内容

- 导数与链式法则（反向传播与雅可比矩阵的基础）
- 泰勒展开（非线性优化的一阶、二阶近似）
- 多元函数梯度、雅可比、海森矩阵
- 积分（概率密度、连续贝叶斯滤波）

### 掌握标准

- 能手推高斯牛顿法的更新式 `Δx = -(JᵀJ)⁻¹Jᵀr`
- 能说明 EKF 在线性化点求雅可比的原因
