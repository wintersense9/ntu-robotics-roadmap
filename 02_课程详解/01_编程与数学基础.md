# 编程与数学基础

这套课里有两门"前置课"（线代、微积分）和一门"工具课"（Modern C++）。它们不是可选项——**跳过它们，后面每门课都会卡在同一个地方**：数学推导看不懂，或者看懂了写不出来。

## 1. Modern C++ for Computer Vision

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | University of Bonn / Cyrill Stachniss |
| 页面 | https://www.ipb.uni-bonn.de/teaching/cpp-2020/ |
| 学期 | T1 |
| 工作量 | 60–80 小时 |
| 前置 | 会任意一门语言（Python/Java/Matlab 都行） |

### 讲什么

面向"要写视觉/机器人程序的人"，不是面向"要写 C++ 编译器的人"。核心是**能读懂并改造 Eigen / OpenCV / ROS 里的 C++ 代码**。

| 模块 | 内容 |
|---|---|
| 编译与构建 | 预处理 / 编译 / 链接、头文件、CMake、多文件工程 |
| 语言核心 | 值/引用/指针、const、类与构造析构、继承、虚函数 |
| 现代特性 | 模板、auto、lambda、智能指针、move 语义、STL 容器与算法 |
| 数值库 | Eigen（矩阵、向量、四元数、块操作）、Sophus（李群入门） |
| 视觉库 | OpenCV 的 Mat、读写、滤波、特征、可视化 |
| 工程化 | 性能分析、多线程、单元测试、Git 协作 |

### 作业与产出

- 3–5 个小程序：矩阵运算、图像滤波、特征提取与匹配、点云变换。
- 每个作业都要用 CMake 组织，不能是单个 .cpp 文件。

### 怎么算学会

- 不看教程，能用 Eigen 写一个"读点云 → 位姿变换 → 投影到图像"的程序；
- 能解释 `std::unique_ptr` 和值语义在什么情况下该用哪个；
- 能给一个现有 CMake 工程加一个可执行目标和依赖。

### 配套

- 书：《Effective Modern C++》（选读，别一上来读完）
- 代码：Eigen 官方 tutorial、OpenCV 官方 tutorial
- 速查：cppreference.com

### 坑

- 不要在这门课上追求"学完 C++"。18 个特性里你只需要 10 个，剩下的用到再查。
- 不要用 Visual Studio 的默认工程结构，学 CMake，后面 ROS/OpenCV 全靠它。
- 模板报错极长，学会从最后一行往前读。

## 2. 18.06 Linear Algebra

| 项目 | 内容 |
|---|---|
| 学校 / 讲者 | MIT / Gilbert Strang |
| 页面 | https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/ |
| 学期 | 前置（T1 之前或并行） |
| 工作量 | 30–40 小时 |
| 前置 | 高中代数 |

### 讲什么

机器人里所有东西最终都是矩阵：位姿是 SE(3)，标定是最小二乘，SLAM 后端是稀疏线性系统，PCA 是 SVD，优化是求导 + 解方程。

必看内容：消元与 LU、四个基本子空间、正交与投影、最小二乘、特征值/特征向量、对称矩阵与正定、SVD。

可以跳过：数值稳定性细节、大规模稀疏求解实现（用到再回来看）。

### 怎么算学会

- 能手算一个 3×3 的最小二乘问题；
- 能说清"为什么旋转矩阵必须是正交且行列式为 1"；
- 能用 SVD 解释"为什么直接线性变换（DLT）能解相机矩阵"。

### 配套

- 书：《Introduction to Linear Algebra》(Strang)
- 补充：3Blue1Brown 的《线性代数的本质》先看一遍建立直觉，再刷 18.06

## 3. 微积分（够用版）

| 项目 | 内容 |
|---|---|
| 资源 | 3Blue1Brown 微积分系列 + MIT 18.01（选看） |
| 学期 | 前置 |
| 工作量 | 20–30 小时 |

### 只需要这些

- 导数、链式法则（反向传播和雅可比矩阵的基础）
- 泰勒展开（非线性优化里的一阶/二阶近似）
- 多元函数梯度、雅可比、海森矩阵
- 积分（概率密度、连续贝叶斯滤波）

### 怎么算学会

- 能手推高斯牛顿法的更新式 `Δx = -(JᵀJ)⁻¹Jᵀr`；
- 能解释"为什么 EKF 要在线性化点求雅可比"。

## 5. 前置补课顺序（建议 6 周）

| 周 | 内容 | 验收 |
|---|---|---|
| 1–2 | 3B1B 线代本质 + 18.06 前 10 讲 | 能解释矩阵乘法 = 线性变换 |

> 这 6 周不要顺手开 Modern C++。先把数学直觉建立起来，C++ 课上讲的投影和变换才有意义。
