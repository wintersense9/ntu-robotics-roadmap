## 2. 与 NTU 课程的对应关系

| 开源课程 | 对应 NTU 课程 | 关系 | 建议 |
|---|---|---|---|
| Modern C++ for CV | 无 | NTU 缺编程课 | **必学**（嵌入式/世界模型），2–3 个月 |
| Photogrammetry I/II | MA6216 Vision | 补 3D 重建 | 选学，世界模型方向必学 |
| Mobile Robotics and Sensing I/II | MA6214 AMR | 高度重叠 | 可当 MA6214 的预习/复习 |
| Multiview Geometry | MA6216 Vision | 深化几何 | AI/世界模型必学 |
| Vision Algorithms for Mobile Robotics | MA6214 + MA6216 | 重叠 + 视觉里程计 | 推荐，代码量大 |
| Deep Learning for CV (EECS498) | MA6211 | 远超 MA6211 深度 | **AI/世界模型必学** |
| 3D Scanning and Motion Capture | MA6220 数字孪生 | 3D 重建 + 动作捕捉 | 世界模型必学 |
| Visual Navigation for AV (MIT) | MA6224 无人车 | 自动驾驶视角 | 选学，想做自驾/无人机必修 |

| Convex Optimization | 无 | NTU 缺优化课 | **世界模型必学**，控制方向推荐 |
| 18.06 Linear Algebra | MA6121 一部分 | 补基础 | 数学不牢先刷 |

## 3. 按方向裁剪后的版本

### AI 方向（约 8 个月，每周 8–10 小时）
```
必修：Modern C++（前 6 周够用）
      → Deep Learning for CV (EECS498)
      → Vision Algorithms for Mobile Robotics
      → Mobile Robotics and Sensing I
选学：Multiview Geometry（想懂 3D 就学）
      Convex Optimization（想做优化/RJ 就学）
```

### 嵌入式方向（约 6 个月）
```
必修：Modern C++（完整学）
      → Mobile Robotics and Sensing I/II（重点看传感器与驱动）
      → Underactuated Robotics（只看动力学建模部分）
选学：Convex Optimization（MPC 需要）
数学：18.06 线代复习
```
> 注意：这套课里**没有 MCU / RTOS / 电机驱动**内容，嵌入式必须另找资源（见 `04_嵌入式硬件入门`）。

### 世界模型方向（约 12 个月）
```
必修：Modern C++ + 18.06 线代
      → Photogrammetry I/II
      → Multiview Geometry
      → Convex Optimization
      → Deep Learning for CV
      → 3D Scanning and Motion Capture
      → Visual Navigation for AV
选修：Underactuated Robotics（model-based RL 必备）
```
> 这套课是**几何 + 视觉**主线，正好是世界模型里"3D 表征"那一支的基础；"生成式视频"那一支要另补扩散模型。

## 4. 学习节奏建议

| 阶段 | 时长 | 内容 | 验收 |
|---|---|---|---|
| 第 1 段 | 6–8 周 | Modern C++ + 18.06 | 能用 Eigen 写一个 3D 点云变换程序 |
| 第 2 段 | 10–12 周 | EECS498 | 手写 ResNet + 训练 CIFAR |
| 第 3 段 | 8–10 周 | Mobile Robotics I/II | 跑通一个 2D 栅格建图 |
| 第 4 段 | 10–12 周 | 视觉几何三门 | 用 COLMAP 重建一个场景 |
| 第 5 段 | 8–12 周 | 优化 / VNAV / Underactuated | 复现一个 MPC 或轨迹优化 demo |

**关键提醒**：这套课的作业量很大（Bonn 的 C++ 课和 Photogrammetry 都有大量编程作业）。不要同时开三门，一次一门，做完作业再下一门，否则会变成"看过 = 学会"的错觉。

## 5. 与原 repo 的差异说明

- 原 repo 是"课程链接聚合"，**不提供证书、不给作业答案、没有助教**；
- 部分链接是往年学期页面（如 2020/2021），视频和作业可能失效，但讲义 PDF 通常还在；
- TUM 的 Multiple View Geometry 与 3D Scanning 需要一定线性代数与概率基础；
- MIT 的 Underactuated 和 VNAV 难度显著高于其他课程，建议放在后期。
