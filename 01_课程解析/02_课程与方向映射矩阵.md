## 2. 三条路线的推荐选课组合

### AI 方向（感知 + 学习 + 决策）
```
Core:   MA6210 + MA6121
Group A: MA6211（AI/ML）+ MA6216（Vision）+ MA6214（AMR）
         → 第 4 门可选 MA6213（数据融合）
Group B: MA6224（无人车，练 EKF + 决策）
Group C: MA6788 独立研究（做 VLA / 抓取学习）
```
逻辑：感知（6216）→ 学习（6211）→ 移动（6214）→ 真实系统（6224）→ 自主研究（6788）。

### 嵌入式方向（控制 + 驱动 + 系统）
```
Core:   MA6210 + MA6121
Group A: MA6212（操作与控制）+ MA6217（线性系统）+ MA6213（传感融合）
         → 可加 MA6214 做移动平台
Group B: MA6501（制造控制）或 MA6223（HRI，如果做协作/康复）
Group C: MA6215 机器人项目（实物集成）
```
逻辑：控制理论（6217）→ 执行器与力控（6212）→ 传感闭环（6213）→ 工业落地（6501）。

### 世界模型方向（预测 + 生成 + 规划）
```
Core:   MA6210 + MA6121
Group A: MA6211（学习）+ MA6216（视觉）+ MA6214（SLAM）
         → 第 4/5 门选 MA6213（估计）
Group B: MA6220（数字孪生）
论文选项: 选 Option 1，用 Dissertation 做世界模型课题
```
逻辑：这个方向课程覆盖最弱，**必须靠 Dissertation + 自学论文**。MA6220 是唯一直接相关的课，但它讲的是工业数字孪生，不是 latent dynamics。

## 4. 一句话定位建议

- 如果你想 **尽快就业**：嵌入式方向，课程几乎全覆盖，补 C++ 和动手即可。
- 如果你想 **进 AI 岗/具身智能公司**：AI 方向，但要接受"课程只给骨架，算法全靠自学"。
- 如果你想 **读博/做研究**：世界模型方向，且必须选论文选项 + 提前锁定导师。
