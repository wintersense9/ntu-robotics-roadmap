# 申请要点与时间线

> 数据来自 NTU 官方页面，截至 2026-11-23。入学季为 **2027 年 8 月**。

## 1. 硬性门槛

| 项目 | 要求 |
|---|---|
| 本科专业 | 工程类，如航空航天、机械、电子电气；相关学科可个案评估 |
| 学位等级 | "good bachelor's degree"，择优录取，不是达线即录 |
| 英语 | TOEFL iBT ≥ 85（PBT ≥ 563，CBT ≥ 223）或 IELTS ≥ 6.0（非英文授课本科） |
| 推荐信 | 2 封，学术或职业导师 |
| 个人陈述 | Statement of Purpose，必须"clear" |
| 其他 | 成绩单、护照、申请费 SGD 50、录取押金 SGD 5000 |

## 2. 时间倒排（以 2027-03-31 截止为锚点）

| 时间 | 要做的事 |
|---|---|
| 2026-11（现在） | 确定方向、开始补先修课（C++/线代/Python）、联系 2 位推荐人 |
| 2026-12 | 考托福/雅思（留一次重考机会）；整理成绩单英文版 |
| 2027-01 | 写 SOP 第一版；确定 3 个目标方向与职业叙事 |
| 2027-02 | SOP 定稿；推荐信催办；提交网申（不要等到 3 月） |
| 2027-03-31 | 申请 + 奖学金表格双截止 |
| 2027-04~06 | 等结果、准备面试（如被 shortlist）、办签证 |
| 2027-08 | 入学 |

## 3. 奖学金

**MAE Graduate Scholarship**
- 额度：全额学费（不含杂费），或酌情 50%
- 不含：SGD 50 申请费、SGD 5000 押金
- 维持条件：每学期 CGPA ≥ 3.50
- 评审维度：学术记录、工作经历、过往成就与奖项
- 可能安排面试
- **需要单独提交申请表**，截止同为 2027-03-31
- 申请表在 NTU MAE 官网 "MAE Graduate Scholarship Application Form"

> 策略：即使自费也先申奖学金，边际成本只是一张表；50% 档也值得。

## 4. 个人陈述（SOP）写作框架

评审看三件事：**你为什么现在读、你为什么选 NTU、你毕业后要做什么**。建议 800–1000 词，结构：

1. **钩子（150 词）**：一个具体的技术经历（做过的小车/机械臂/算法项目），引出你对"机器人系统"的兴趣。
2. **能力证明（250 词）**：本科课程 + 项目 + 编程能力，证明你能跟上 MA6212/MA6217 这类硬课。
3. **为什么是 NTU（200 词）**：点名 3–4 门课（如 MA6213 + MA6214 + MA6216），说明组合逻辑；点名 RRC 或某位教授的研究方向。
4. **方向与职业规划（250 词）**：明确一条路线（AI / 嵌入式 / 世界模型），说明毕业后 3–5 年目标。
5. **结尾（100 词）**：总结匹配度。

**常见错误**：
- 通篇"我热爱机器人"但没有项目证据；
- 把 NTU 当"新加坡排名高所以想去"；
- 三个方向都想写，结果没有一个写深。

## 5. 推荐信策略

- 首选：带过你项目/毕业设计的老师（能讲具体技术细节）；
- 次选：实习主管（能讲工程能力与协作）；
- 提前 4–6 周给推荐人一份"材料包"：成绩单、简历、SOP 草稿、你做过的项目清单、你希望他强调的 2–3 个点。

## 6. 选课选项决策：Option 1（论文）还是 Option 2（纯课程）

| | Option 1：课程 + 论文 | Option 2：纯课程 |
|---|---|---|
| 学制 | 全日制约 1.5 年 | 1 年 |
| 适合 | 想读博、想进研发岗、想做出一个能写进简历的研究成果 | 想尽快就业、想多修课拓宽面 |
| 代价 | 多半年时间与生活费；需要提前找到导师 | 没有研究成果，作品集靠自己攒 |
| 建议 | **世界模型方向必选**；AI 方向强烈建议 | 嵌入式方向可选，用 MA6215 项目替代 |

> 转选项只能在第一学期通过 "Application for Conversion of Option of study" 表格申请，错过就默认纯课程。

## 7. 入学前 6 个月该做什么（按方向）

- **共同**：线性代数复习、Python 熟练、Linux 基本操作、Git。
- **AI**：PyTorch + 一门深度学习课（EECS498 前 6 讲）。
- **嵌入式**：买一块 STM32 或 ESP32 开发板，把 GPIO/定时器/串口/PWM 跑一遍。
- **世界模型**：概率论 + 凸优化前 4 讲 + 跑通一个 diffusion 的最小实现。

不要提前自学 NTU 的具体课程内容——先把工具链和数学补齐，收益更高。
