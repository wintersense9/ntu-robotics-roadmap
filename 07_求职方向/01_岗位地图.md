## 3. 地域差异

### 新加坡
- **强项**：精密制造、半导体设备、物流自动化、医疗科技、海事
- **公司**：ST Engineering、A*STAR（研究）、Dyson（新加坡总部）、Shopee 物流、各半导体设备商（Applied Materials、ASM、KLA）
- **特点**：纯 AI 岗少于中美，系统集成/嵌入式岗更稳；EP 签证对薪资有门槛
- **薪资**：硕士应届机器人/嵌入式约 SGD 4,500–6,500/月；算法岗略高；研究岗看机构

### 中国大陆
- **具身智能**：宇树、智元、银河通用、星海图、优必选、傅利叶、非夕
- **大厂**：字节 Seed、阿里达摩院、腾讯 Robotics X、小米、华为车 BU
- **自动驾驶**：Momenta、小鹏、蔚来、理想、地平线
- **嵌入式**：大疆、汇川、埃斯顿、节卡、遨博
- **薪资**：硕士算法 30–60 万/年，嵌入式 20–40 万/年，头部具身智能可更高

### 北美/欧洲
- Physical Intelligence、Figure、1X、Tesla Optimus、Boston Dynamics、Agility
- DeepMind、Meta FAIR、NVIDIA GEAR
- 通常要求博士或顶会论文

> 薪资数据为区间估计，随市场波动，仅作量级参考。

## 4. 岗位 JD 关键词拆解

### 具身智能算法工程师（典型 JD）
```
必备：
- 熟悉 PyTorch，有大规模训练经验
- 熟悉模仿学习 / 强化学习 / 扩散策略
- 有真机部署经验（机械臂/移动平台）
- 熟悉 ROS 2
加分：
- 顶会论文（CoRL / RSS / ICRA / IROS / NeurIPS）
- VLA 模型经验
- 多模态大模型经验
```

### 机器人固件工程师（典型 JD）
```
必备：
- 精通 C/C++，熟悉 STM32 或类似 MCU
- 熟悉 FreeRTOS / RT-Thread
- 熟悉 CAN / UART / SPI / I2C
- 有电机控制（FOC / PID）经验
加分：
- EtherCAT
- 功能安全（ISO 13849 / IEC 61508）
- 量产经验
```

### SLAM 算法工程师（典型 JD）
```
必备：
- 精通 C++，熟悉 Eigen / Ceres / GTSAM
- 熟悉 ORB-SLAM / VINS / LIO-SAM 之一
- 熟悉多视图几何、状态估计
加分：
- 激光-视觉-惯性融合
- 大规模建图
- 嵌入式部署
```

## 5. 求职时间线（硕士）

| 时间 | 动作 |
|---|---|
| 入学前 | 完成 1 个项目，建立 GitHub |
| 第一学期 | 投寒假实习（10–12 月投递） |
| 第一学期末 | 确定毕业方向，开始论文 |
| 第二学期初 | 投暑期实习（2–4 月） |
| 毕业前 6 个月 | 秋招/春招投递（中国 8–10 月秋招） |
| 毕业前 3 个月 | 补投、面试冲刺 |

**新加坡**：应届招聘周期较灵活，但大公司（ST Engineering 等）有固定校招窗口，提前关注。

## 6. 面试常见问题（按方向）

### AI
- 解释 Diffusion Policy 的训练目标
- 模仿学习的分布偏移怎么缓解
- 你的模型在真机上延迟多少，怎么优化
- 为什么选这个 backbone
- 数据怎么采的，有多少条，失败样本怎么处理

### 嵌入式
- PID 三个参数分别影响什么
- 为什么用 DMA，不用会怎样
- 中断优先级怎么设计
- 电机启动时 MCU 复位，怎么排查
- FOC 的三个环带宽关系

### 世界模型
- Dreamer 的 RSSM 结构
- 为什么在 latent 空间预测而不是像素
- 世界模型的误差累积怎么处理
- 你的复现和论文差多少，为什么
