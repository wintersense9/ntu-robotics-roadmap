# NTU 申请要点与时间线

> 数据来自 NTU 官方项目页，截至 2026-11-23。目标入学季 2027 年 8 月。仅作为本仓库的附录——如果你不申 NTU，这页可以跳过。

---

## 1. 硬性门槛

| 项目 | 要求 |
|---|---|
| 本科专业 | 工程类（航空航天、机械、电子电气等），相关学科个案评估 |
| 学位等级 | "good bachelor's degree"，择优录取 |
| 英语 | TOEFL iBT ≥ 85 或 IELTS ≥ 6.0（非英文授课本科） |
| 材料 | 成绩单、2 封推荐信、Statement of Purpose、护照 |
| 费用 | 申请费 SGD 50，录取押金 SGD 5000 |

---

## 2. 时间倒排

| 时间 | 要做的事 |
|---|---|
| 2026-11（现在） | 开始补前置（线代/C++/Python）、联系 2 位推荐人 |
| 2026-12 | 考托福/雅思（留一次重考余量）；准备成绩单英文版 |
| 2027-01 | SOP 第一版；确定"想做哪类机器人"的技术叙事 |
| 2027-02 | SOP 定稿；催推荐信；**尽早提交网申** |
| 2027-03-31 | 申请 + MAE 奖学金表格双截止 |
| 2027-04~06 | 等结果、准备面试、办签证 |
| 2027-08 | 入学 |

---

## 3. 奖学金（MAE Graduate Scholarship）

- 额度：全额学费，或酌情 50%
- 不含：SGD 50 申请费、SGD 5000 押金
- 维持条件：每学期 CGPA ≥ 3.50
- 需**单独提交申请表**，截止与申请同为 2027-03-31
- 可能安排面试

> 即使打算自费也先申，边际成本只是一张表。

---

## 4. SOP 框架（800–1000 词）

评审只看三件事：**你为什么现在读、为什么选 NTU、毕业后做什么**。

| 段落 | 字数 | 写什么 |
|---|---|---|
| 钩子 | 150 | 一个具体的技术经历（做过的小车/视觉项目），引出对"机器人系统"的兴趣 |
| 能力证明 | 250 | 本科课程 + 项目 + 代码能力，证明能跟上 MA6212/MA6217 |
| 为什么 NTU | 200 | 点名 3–4 门课（如 MA6213 + MA6214 + MA6216）说明组合逻辑，点名 RRC 或某位教授 |
| 规划 | 250 | 想做哪类机器人（移动/机械臂/感知/控制），毕业后 3–5 年目标 |
| 结尾 | 100 | 匹配度总结 |

**常见错误**：通篇"我热爱机器人"没有项目证据；只说"排名高"；把五个方向都写一遍导致没有一个写深。

---

## 5. 推荐信

- 首选带过你项目/毕业设计的老师（能讲技术细节）
- 次选实习主管（能讲工程能力）
- 提前 4–6 周给一份材料包：成绩单、简历、SOP 草稿、项目清单、希望他强调的 2–3 个点

---

## 6. Option 1（课程 + 论文）还是 Option 2（纯课程）

| | Option 1 | Option 2 |
|---|---|---|
| 学制 | 全日制约 1.5 年 | 1 年 |
| 适合 | 想读博、想做出研究成果 | 想尽快就业、多修课 |
| 代价 | 多半年时间与生活费，需提前找到导师 | 没有研究成果，作品集自己攒 |
| 建议 | 想做研究/进研发岗选它 | 想做工程岗选它 |

> 转选项只能第一学期申请（"Application for Conversion of Option of study"），错过默认纯课程。
