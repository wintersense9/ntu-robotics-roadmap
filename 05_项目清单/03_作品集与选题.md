# 作品集与论文选题

## 1. 作品集的"三件套"结构

面试官/招生官看作品集只有 30 秒，所以要结构化：

```
作品 1：硬件闭环（证明你能碰真机）
    例：1 kHz 电机电流环 + ROS 2 集成
    关键词：实时、稳定、可复现

作品 2：算法复现（证明你能读论文并落地）
    例：ACT 抓取 / ORB-SLAM3 / DreamerV3
    关键词：复现、评测、改进

作品 3：系统集成（证明你能做完整系统）
    例：移动抓取 / 数字孪生 / 四足
    关键词：端到端、多模块、演示
```

**为什么是这个组合**：单有算法会被质疑"没碰过硬件"；单有硬件会被质疑"不懂原理"；有系统集成才能证明综合能力。

## 2. 作品集页面模板（GitHub / 个人主页）

```markdown
## 项目名
一句话：用 XX 方法解决 XX 问题，达到 XX 指标

![demo gif]

- 硬件：...
- 软件：...
- 我的工作：...(具体到模块)
- 结果：...（量化）
- 失败与改进：...（至少 2 条）
- 代码 / 视频：[链接]
```

**量化示例**：
- 差：""实现了电机控制""
- 好：""实现 1 kHz 电流环，阶跃响应 2 ms，稳态误差 < 1%""

## 3. 毕业论文选题（结合 NTU 导师方向）

NTU MAE 的 RRC 主要方向：Autonomous Systems、Embodied Intelligence、BioRobotics、Rehabilitation Engineering、Smart Mobility、Robotic Microsurgery、Robotic Materials、Human-Robot Interaction。

### AI 方向可选题目
| 题目 | 难度 | 数据/硬件 |
|---|---|---|
| 小样本语言条件抓取（VLA 微调） | ★★★ | SO-100 + 公开数据集 |
| 多相机融合的透明物体抓取 | ★★★★ | D405 + 自制数据 |
| 基于扩散策略的柔性物体操作 | ★★★★ | 机械臂 + 布料数据集 |
| 机器人操作的数据增强与仿真预训练 | ★★★ | Isaac Lab + 真机 |

### 嵌入式方向可选题目
| 题目 | 难度 | 硬件 |
|---|---|---|
| 基于 FOC 的力控关节设计与实现 | ★★★ | 云台电机 + SimpleFOC |
| 多电机 EtherCAT 同步控制 | ★★★★ | 伺服驱动 + 主站 |
| 康复外骨骼的阻抗控制 | ★★★★ | 外骨骼 + 力传感器 |
| 低成本机械臂的精度标定与补偿 | ★★★ | SO-100 + 激光跟踪仪/相机 |

### 世界模型方向可选题目
| 题目 | 难度 | 算力 |
|---|---|---|
| Dreamer 在机械臂抓取中的样本效率研究 | ★★★★ | 24G GPU |
| 3DGS 场景表示用于抓取位姿评估 | ★★★ | 12G GPU |
| 世界模型辅助的 sim-to-real 迁移 | ★★★★★ | 多卡 |
| 视频预测模型的物理一致性评测 | ★★★★ | 大显存 |

**选题原则**：
1. 导师有相关积累 > 题目热门
2. 能在 6–9 个月做完 > 野心大
3. 有真机/真实数据 > 纯仿真（除非做理论）
4. 有一个明确的 baseline > 从零造轮子

## 6. 常见减分项

1. **只有课程作业**：没有自主项目，说明缺乏内驱力。
2. **只有截图没有视频**：机器人项目必须动起来。
3. **没有量化指标**："效果不错"是无效描述。
4. **GitHub 没有 README**：代码扔上去不等于作品。
5. **全是仿真**：会被问"真机上试过吗"。
6. **项目之间无关联**：三个项目各做各的，说明没有主线。
7. **不能解释失败**：只讲成功案例，会被认为没真正做过。

---

## 7. 一句话总结

**作品集不是"我做过什么"的清单，而是"我能解决什么类型问题"的证据链。** 三个项目要指向同一个职业叙事。
