# 进阶项目清单（10 个）

这些项目用于：作品集主体、硕士课程项目、毕业论文预研、求职面试谈资。

---

### 1. SO-100 模仿学习抓取
- **方向** AI / 嵌入式 / 世界模型 都能用
- **周期** 4–6 周 / **硬件** SO-100 + 摄像头（¥2500 档）
- **做什么**：遥操作采集 50–100 条演示 → ACT 或 Diffusion Policy 训练 → 真机部署 → 分析失败案例。
- **验收**：未见过的物体抓取成功率 ≥ 60%；有失败分析。
- **简历**：基于 ACT 的桌面抓取策略，自采数据 100 条，成功率 65%。
- **加分**：加数据增强、加多相机、换成语言条件（VLA 雏形）。

---

### 2. 视觉伺服抓取
- **方向** AI / 嵌入式
- **周期** 3–4 周 / **硬件** 机械臂 + RealSense D405
- **做什么**：手眼标定 → 目标检测（YOLO/SAM）→ 6D 位姿估计（FoundationPose）→ 运动规划（MoveIt2）→ 抓取。
- **验收**：5 类物体抓取成功率 ≥ 80%，标定误差 < 5 mm。
- **简历**：实现 Eye-in-Hand 手眼标定与 6D 位姿估计抓取流水线。
- **对应课程**：MA6212 + MA6216

---

### 3. ORB-SLAM3 / FAST-LIO2 复现
- **方向** AI / 世界模型
- **周期** 3–4 周 / **硬件** 数据集 + 可选 RealSense/LiDAR
- **做什么**：编译运行 → 在 TUM/EuRoC 数据集上评测 → 改一个模块（如特征提取）做对比。
- **验收**：ATE/RPE 指标接近论文；有改进前后对比表。
- **简历**：复现 ORB-SLAM3 并在 EuRoC 上完成精度评测与特征模块改进。
- **对应课程**：MA6214

---

### 4. 3DGS 场景重建 + 抓取评估
- **方向** 世界模型
- **周期** 3–4 周 / **硬件** 手机视频 + 12G GPU
- **做什么**：拍摄桌面场景视频 → COLMAP 位姿 → 3DGS 训练 → 导出点云 → 用点云做抓取位姿采样。
- **验收**：重建 PSNR > 28；抓取候选位姿可视化合理。
- **简历**：基于 3D Gaussian Splatting 重建桌面场景并用于抓取位姿采样。
- **对应课程**：MA6216 + MA6220

---

### 5. DreamerV3 复现与消融
- **方向** 世界模型
- **周期** 4–6 周 / **硬件** 24G GPU
- **做什么**：跑通 DMC 的 cheetah/walker → 复现论文曲线 → 消融 KL balancing 或 RSSM 结构。
- **验收**：曲线与论文差距 < 20%；有消融实验表。
- **简历**：复现 DreamerV3 并完成 RSSM 结构消融实验。
- **对应课程**：MA6211 + MA6788

---

### 6. Isaac Lab 四足行走 + sim-to-real
- **方向** AI / 嵌入式
- **周期** 6–8 周 / **硬件** 24G GPU + 四足（可选）
- **做什么**：legged_gym 环境 → PPO 训练 → 域随机化 → 仿真验证 → 真机（如有）。
- **验收**：仿真中能稳定行走 60 s；有域随机化前后对比。
- **简历**：基于 Isaac Lab 训练四足运动策略，完成域随机化与仿真验证。
- **对应课程**：MA6212 + MA6217

---

### 7. 移动抓取系统
- **方向** 全栈
- **周期** 8–12 周 / **硬件** 15000 档
- **做什么**：底盘导航（Nav2）+ 机械臂（MoveIt2）+ 视觉检测 + 任务状态机。
- **验收**：能在未知房间中找到目标物体并抓取。
- **简历**：搭建移动抓取平台，集成 Nav2 导航与 MoveIt2 操作，完成端到端任务。
- **对应课程**：MA6214 + MA6212 + MA6215

---

### 8. 力控装配（轴孔插入）
- **方向** 嵌入式
- **周期** 4–6 周 / **硬件** 机械臂 + 力传感器（或用电流估算）
- **做什么**：阻抗控制 / 导纳控制 → 螺旋搜索策略 → 插入检测。
- **验收**：间隙 0.2 mm 的轴孔插入成功率 ≥ 70%。
- **简历**：实现基于阻抗控制的轴孔装配，插入成功率 70%。
- **对应课程**：MA6212 + MA6217

---

### 9. 数字孪生（MuJoCo/Isaac 同步）
- **方向** 世界模型 / 嵌入式
- **周期** 4–6 周 / **硬件** 机械臂 + GPU
- **做什么**：真机状态 → UDP/MQTT → 仿真同步 → 在仿真里预演动作 → 回传真机。
- **验收**：仿真与真机姿态误差 < 2°；能预演一个避障动作。
- **简历**：构建机械臂数字孪生系统，实现真机-仿真状态同步与动作预演。
- **对应课程**：MA6220

---

### 10. 无人机/无人车 EKF 导航
- **方向** AI / 嵌入式
- **周期** 4–6 周 / **硬件** Crazyflie 或小车 + GPS/视觉
- **做什么**：IMU + 视觉/激光 + EKF 融合 → 路径跟踪 → 抗风/抗扰测试。
- **验收**：轨迹跟踪误差 < 0.3 m；有干扰前后对比。
- **简历**：实现多传感器 EKF 融合与轨迹跟踪控制。
- **对应课程**：MA6224 + MA6213

## 项目交付标准（每个都要有）

1. **代码仓库**：README（背景、方法、运行方式、结果）+ 依赖锁文件
2. **演示视频**：2–3 分钟，包含失败案例
3. **技术报告**：3–5 页，含架构图、实验表、失败分析
4. **可复现**：别人 clone 后能按 README 跑通
5. **数据/模型**：能开源的开源，不能开源的说明原因

> 面试官最看重的不是"你做成了"，而是"你知道为什么失败"。每个项目至少写 3 条失败分析。
