# 嵌入式方向：课程与学习路线

嵌入式是机器人系统中"让算法真正动起来"的部分：传感器采样、姿态解算、电机驱动、实时控制、与上位机通信。本页列出对应课程与学习顺序，与前五门视觉类课程相互独立，可单独学习。

---

## 1. 能力构成

| 环节 | 解决的问题 | 主要工具 |
|---|---|---|
| C 语言与底层编程 | 寄存器操作、内存与指针、中断 | C、Keil / STM32CubeIDE、PlatformIO |
| MCU 外设 | 定时器、PWM、ADC、DMA、通信接口 | STM32（F1/F4/H7）、ESP32 |
| 实时操作系统 | 任务调度、优先级、资源同步 | FreeRTOS、Zephyr |
| 电机与运动控制 | 闭环控制、FOC、编码器、驱动器 | SimpleFOC、ODrive、汇川/步科驱动器 |
| 机器人集成 | 与 ROS 2 通信、协议设计、时间同步 | micro-ROS、CAN、EtherCAT、串口协议 |
| 硬件基础 | 电路阅读、信号测量、PCB 修改 | 万用表、示波器、逻辑分析仪、KiCad |

## 3. 学习路线

### 阶段 1：C 语言与最小系统
- 内容：指针、结构体、位运算、内存分区；点亮 LED、按键消抖、串口打印。
- 工具：STM32F103 最小系统板、ST-Link、STM32CubeIDE 或 PlatformIO。
- 产出：能用寄存器或 HAL 完成 GPIO 与串口收发，能读懂启动文件与链接脚本。

### 阶段 2：外设与通信
- 内容：定时器与 PWM、ADC 采样与滤波、DMA、外部中断、I2C/SPI 传感器读取。
- 器件：MPU6050/ICM42688（IMU）、AS5600（磁编码器）、OLED、气压计。
- 产出：能读取 IMU 原始数据并做零偏校准与姿态解算（互补滤波或 Mahony）。

### 阶段 3：RTOS 与多任务
- 内容：任务划分、优先级设计、队列与信号量、临界区、看门狗、低功耗。
- 产出：把采样、控制、通信拆成独立任务，并保证控制周期稳定在毫秒级。

### 阶段 4：电机与闭环控制
- 内容：直流有刷电机 H 桥、无刷电机 FOC、编码器测速、电流环与位置环、串级 PID。
- 器件：SimpleFOC 驱动板或 ODrive、无刷电机、磁编码器。
- 产出：完成速度闭环与位置闭环，阶跃响应超调与稳态误差可测量。

### 阶段 5：机器人集成
- 内容：与上位机协议设计（帧头、校验、超时）、CAN 通信、micro-ROS 接入、时间同步。
- 产出：STM32 侧作为 ROS 2 的一个节点，发布传感器数据并接收速度指令。

### 阶段 6：整机项目
- 项目选项：自平衡小车、二轴云台、机械臂关节模组、四足单腿测试台。
- 产出：一台可稳定运行的样机，包含固件、上位机代码与调试记录。

## 4. 与视觉类课程的关系

| 组合 | 适用 |
|---|---|
| 只学嵌入式 | 固件、驱动、运动控制、飞控、伺服岗位 |
| 嵌入式 + 视觉导航 | 无人机、移动机器人整机开发 |
| 嵌入式 + VNAV / Underactuated | 腿足、机械臂控制算法 |
| 嵌入式 + EECS498 | 边缘端模型部署（TensorRT、NPU） |

视觉课程解决"感知与决策"，嵌入式课程解决"执行与实时性"。整机岗位通常同时要求两部分。

## 5. 器件与工具的最小配置

| 类别 | 建议 |
|---|---|
| 主控 | STM32F103（入门）、STM32F407 或 H743（进阶）、ESP32-S3（无线） |
| 调试 | ST-Link V2、USB-TTL、逻辑分析仪（8 通道）、示波器（≥100 MHz，二手可用） |
| 执行器 | 有刷电机 + 编码器、无刷电机 + SimpleFOC 驱动板 |
| 传感器 | IMU（ICM42688）、磁编码器（AS5600）、超声波或 ToF |
| 软件 | STM32CubeIDE / PlatformIO、FreeRTOS、KiCad（改板用） |

## 6. 学习中的常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 程序下载后不运行 | 时钟配置或启动文件不匹配 | 核对时钟树与 linker script |
| 串口乱码 | 波特率或时钟源偏差 | 用示波器测实际波特率 |
| 电机抖动、发热 | 电流环参数或 PWM 死区设置错误 | 先开环测相电流，再加闭环 |
| 控制周期不稳定 | 中断中执行耗时操作 | 中断只做标记，运算放主循环或高优先级任务 |
| 通信丢包 | 无校验、无超时、缓冲区溢出 | 增加帧头、CRC、超时重传 |
| I2C 读取失败 | 上拉电阻缺失或地址错误 | 查上拉与地址，用逻辑分析仪看时序 |
