# ESP32 实践教程

本页按项目类型整理 ESP32 的实践教程：机械臂、小车（遥控、循迹、避障、图传、平衡车）、以及基于 ROS 2 的小车导航。选用标准为有完整代码或接线说明、可复现。

## 4. 基于 ROS 2 的小车导航

前提：Nav2 与 SLAM 需要运行 Linux 的主机（树莓派、Jetson 或 x86），ESP32 作为底层驱动板负责电机、编码器与传感器采集，两者通过 micro-ROS 通信。

| 教程 | 说明 |
|---|---|
| [linorobot2](https://linorobot.github.io/linorobot2/) | ROS 2 差速、麦轮、履带机器人框架，底层控制器支持 ESP32，集成 Nav2、SLAM Toolbox、robot_localization |
| [linorobot2 安装与配置](https://linorobot.github.io/linorobot2/installation/) | 选择 `2wd / 4wd / mecanum` 与激光雷达或深度相机，按向导生成固件 |
| [micro-ROS FreeRTOS 第一个应用](https://micro.ros.org/docs/tutorials/core/first_application_rtos/freertos/) | 让 ESP32 成为 ROS 2 节点，并运行 agent 建立通信 |
| [micro_ros_espidf_component](https://components.espressif.com/components/micro-ros/micro_ros_espidf_component/versions/27.0.0-rolling.20261002/examples/int32_publisher_custom_transport_usbcdc?language=en) | 在 ESP-IDF 工程中直接引入 micro-ROS 的示例 |

推进顺序：micro-ROS 发布与订阅基础话题 → 发布 `/odom`、订阅 `/cmd_vel` → 接入 linorobot2 → 加激光雷达运行 SLAM Toolbox → 使用 Nav2 导航。

## 5. 三条推荐路线

| 路线 | 顺序 |
|---|---|
| 机械臂 | 复现遥控机械臂 → 加摄像头与颜色识别做分拣 → 总线舵机与轨迹插补 |
| 小车 | 蓝牙遥控 → 循迹（比例控制）→ ToF 或超声波避障 → ESP32-CAM 图传 → 平衡车 |
| 导航 | micro-ROS 基础通信 → 里程计发布与速度订阅 → linorobot2 底盘 → SLAM + Nav2 |

## 6. 硬件与常见问题

| 项目 | 建议 |
|---|---|
| 主控 | ESP32-WROOM-32（入门）、ESP32-S3（带 USB 与 AI 指令）、ESP32-CAM（图传） |
| 舵机驱动 | PCA9685（16 通道 I2C），4 路以上舵机必选 |
| 电机驱动 | TB6612FNG（小电流）、L298N（大电流）、SimpleFOC 驱动板（无刷） |
| 传感器 | MPU6050/ICM42688、AS5600 编码器、HC-SR04 或 VL53L0X |

常见问题：

- 电机启动时主控复位：电机与主控分开供电，共地但不共电源
- 舵机抖动：确认 PWM 频率为 50 Hz，检查电源电流是否足够
- ESP32 无 CAN 控制器：需要外挂 MCP2515 或使用带 CAN 的型号（ESP32-S3 部分模组仍需外扩）
- Wi-Fi 与电机 PWM 互相干扰：降低 PWM 频率或使用带屏蔽的电机线
