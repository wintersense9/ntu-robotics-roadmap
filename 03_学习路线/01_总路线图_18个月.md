# 总路线图：入学前 9 个月 + 在读 12 个月

前提：2027 年 8 月入学，现在 2026 年 11 月。下面按"月"给节奏，不按"周"，留出容错空间。

## 0. 全局节奏（三段时间）

```
阶段 A｜2026.11 – 2027.07（入学前 9 个月）
  目标：补齐工具链 + 数学 + 选定方向，并做出 1 个可见成果

阶段 B｜2027.08 – 2028.02（第一学期 + 寒假）
  目标：课程拿高分 + 锁定导师 + 启动方向项目

阶段 C｜2028.03 – 2028.07（第二学期 + 毕业）
  目标：完成毕业要求 + 作品集 + 求职/申博
```

---

## 1. 阶段 A：入学前 9 个月（2026.11 – 2027.07）

### 2026.11 — 定位月
- 读完 `02_方向选择/01_三大方向对比.md`，写下决策结论
- 安装 Ubuntu 22.04（双系统或 WSL2）+ ROS 2 Humble
- Python 环境：conda/uv + PyTorch（确认能调用 GPU）
- 产出：一份 1 页的《方向决策 + 课程选择》笔记

### 2026.12 — 数学与编程地基
- 线性代数：MIT 18.06 前 15 讲（重点：矩阵分解、最小二乘、特征值）
- Python 工程：类型注解、虚拟环境、Git 工作流
- C++：Modern C++ 前 6 周（指针、引用、类、RAII、Eigen 基础）
- 产出：用 Eigen 写一个 3D 点云坐标变换 + 旋转矩阵转四元数的小程序

### 2027.01 — 机器人通识
- 《Modern Robotics》或 Siciliano《Robotics》前 5 章：变换、正运动学、逆运动学
- ROS 2 官方 Tutorials 全部过一遍（pub/sub、service、action、tf2、launch）
- 产出：一个两轮差速小车的 URDF + Gazebo 里能开动

### 2027.02 — 深度学习
- Michigan EECS498 前 8 讲：反向传播、CNN、训练技巧
- 手写一个 ResNet-18，在 CIFAR-10 上跑到 92%+
- 产出：训练曲线 + 一份实验报告

### 2027.03 — 申请冲刺（与学习并行）
- SOP 定稿、推荐信、网申提交、奖学金表提交
- 学习降速，只保留每天 1 小时
- 产出：所有申请材料提交完成

### 2027.04 — 方向专精（第一轮）
按方向二选一：
- **AI**：跑通 LeRobot 的 ACT 训练脚本（仿真或公开数据集）
- **嵌入式**：STM32 上完成"编码器 + PID + 串口上位机"
- **世界模型**：跑通 DreamerV3 的 CartPole 复现

### 2027.05 — 方向专精（第二轮）
- **AI**：用自己的数据训一个抓取/分类策略
- **嵌入式**：FreeRTOS 重构 + CAN 总线通信
- **世界模型**：读 DreamerV3 + TD-MPC2 论文，写对比笔记

### 2027.06 — 系统集成
- 做一个"感知 → 决策 → 执行"的最小闭环：
  - AI：相机检测 → 机械臂抓取
  - 嵌入式：MCU 控电机 → 树莓派发指令
  - 世界模型：仿真环境 → 模型预测 → 规划
- 产出：一段 2 分钟 demo 视频

### 2027.07 — 收尾与预习
- 整理作品集仓库（README + 视频 + 代码）
- 预习 NTU 课表：MA6210 的 reading list、MA6212 的控制基础
- 办签证、订住宿、准备行前

## 2. 阶段 B：第一学期（2027.08 – 2028.02）

### 选课建议（第一学期）
- 必修：MA6210 + MA6121
- 加 1–2 门：MA6214（AMR）或 MA6213（传感融合）——这两门是后续所有方向的地基
- 不要第一学期就选 MA6217（难度高，先适应节奏）

### 关键动作
1. **第 2 周**：去 RRC 的 seminar，记录 5 位教授的研究方向
2. **第 4 周**：给 2–3 位教授发邮件，问 Independent Study / Dissertation 可能性
3. **第 8 周**：确定毕业论文方向（如果要选 Option 1，这学期末必须提交转换表）
4. **寒假**：把方向项目推进到"能演示"的程度

## 3. 阶段 C：第二学期（2028.01 – 2028.07）

### 选课建议
- AI：MA6211 + MA6216 + MA6224
- 嵌入式：MA6212 + MA6217 + MA6501

4. 开始投递：提前 3–4 个月准备（新加坡应届招聘周期偏早）

- **AI**：上半年重"算法复现"，下半年重"真机部署 + 数据"。
- **嵌入式**：上半年重"MCU + 电机"，下半年重"ROS 2 集成 + 完整平台"。
- **世界模型**：上半年重"数学 + 论文"，下半年重"复现 + 论文写作"。
