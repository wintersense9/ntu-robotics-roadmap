# 嵌入式方向学习路线（分阶段）

目标：毕业时能独立设计"MCU 控制层 + ROS 2 上层"的完整机器人子系统，具备机器人本体公司/汽车电子/工业自动化岗位竞争力。

---

## 阶段 0：工具准备（1 周）

### 硬件
- STM32 Nucleo-F446RE 或 STM32F411 Black Pill
- ST-Link V2 调试器（Black Pill 需要）
- 面包板、杜邦线、万用表、USB 转 TTL
- 逻辑分析仪（8 通道，约 50 元，强烈建议）

### 软件
- STM32CubeIDE 或 PlatformIO（推荐 PlatformIO + VSCode）
- 串口助手（如 VOFA+ / Serial Studio，可画波形）
- Ubuntu（放虚拟机或双系统，后面 ROS 2 用）

### 验收
- 能烧录 blink 程序，能用串口打印

---

## 阶段 1：C 与 MCU 外设（6–8 周）

### 学什么
| 内容 | 要点 |
|---|---|
| C 语言 | 指针、结构体、位域、`volatile`、回调函数 |
| GPIO | 推挽/开漏、上下拉、按键消抖 |
| 定时器 | 基础定时、PWM 输出、输入捕获 |
| 串口 | 中断 + DMA + 空闲中断收不定长帧 |
| ADC | 多通道 + DMA + 滑动平均滤波 |
| 中断系统 | NVIC 优先级、抢占、临界区 |

### 项目
1. 按键控制 LED + 串口打印状态
2. PWM 调光（呼吸灯）
3. 串口协议：自定义帧头 + 长度 + 校验 + 数据
4. ADC 采集电位器 + 上位机实时曲线

### 验收
- 能手写定时器中断，不用 HAL 的 `HAL_Delay`
- 能解释为什么串口要用 DMA + 空闲中断

---

## 阶段 2：传感与执行器（6–8 周）

### 学什么
- IMU：SPI 读 MPU6050/ICM42688，互补滤波或 Mahony 解算姿态
- 编码器：定时器编码器模式，四倍频计数
- 直流电机：PWM + H 桥（TB6612/DRV8871）
- PID：位置式/增量式、抗积分饱和、采样周期影响
- 舵机：PWM 控制、总线舵机协议（Dynamixel Protocol 2.0 选学）

### 项目
1. 电机闭环调速（编码器 + PID，目标转速阶跃响应）
2. 电机位置闭环（转到指定角度，误差 < 1°）
3. IMU 姿态显示（串口上位机 3D 姿态）
4. 云台稳定（IMU + 舵机，抵消手抖）

### 验收
- 能给出一条阶跃响应曲线并解释超调、稳态误差
- 能说清 PWM 频率、死区、电流限制对电机的影响

---

## 阶段 3：RTOS 与通信（6 周）

### 学什么
- FreeRTOS：任务、优先级、队列、信号量、互斥锁、软件定时器
- 栈溢出检测、看门狗、低功耗模式
- CAN：帧格式、仲裁、过滤器、波特率计算
- 多机通信：主从协议、心跳、错误处理

### 项目
1. 用 FreeRTOS 重构阶段 2 的电机项目（控制任务 + 通信任务 + 显示任务）
2. 两块板子通过 CAN 通信，一块发指令一块执行
3. 加入看门狗与故障恢复

### 验收
- 能画出任务优先级与资源依赖图
- 能解释优先级反转及互斥锁如何解决

---

## 阶段 4：Linux + ROS 2 集成（8 周）

### 学什么
- Ubuntu 基本操作、SSH、systemd
- ROS 2：节点、话题、服务、Action、参数、launch
- micro-ROS：MCU 作为 ROS 2 节点
- 树莓派/Jetson 与 MCU 的串口/CAN 桥接
- 时间同步与频率设计（控制 1 kHz、感知 30 Hz）

### 项目
1. 树莓派上跑 ROS 2，通过串口控制 STM32 电机
2. 用 micro-ROS 把 IMU 数据发布成 `sensor_msgs/Imu`
3. 用 `ros2_control` 封装一个电机驱动硬件接口

### 验收
- 能在 RViz 里看到真实 IMU 的姿态
- 能说清 `ros2_control` 的 hardware interface 生命周期

---

## 阶段 5：电机控制进阶（8–10 周，可选但推荐）

### 学什么
- BLDC/PMSM 原理、六步换相
- FOC：Clarke/Park 变换、SVPWM、电流环
- 无感控制（反电动势观测器）
- 力控：电流 → 力矩、阻抗/导纳控制

### 项目
- 用 SimpleFOC 或 ODrive 驱动一个云台电机，做力矩模式
- 或：用 Moteus/ODrive 做一个力控关节

### 验收
- 能说清 FOC 三个环（电流、速度、位置）的带宽关系
- 能测出一条电流-力矩曲线

---

## 阶段 6：完整系统（8–12 周）

### 项目（选一个）
- **A：移动抓取平台**：差速底盘 + 6 轴臂 + ROS 2 导航 + MoveIt2
- **B：四足机器人**：12 个舵机 + IMU + 步态控制
- **C：力控装配**：机械臂 + 六维力传感器 + 插孔任务

### 交付
- 完整 BOM、原理图/接线图、固件仓库、ROS 2 包、演示视频

## 避坑清单

1. **先共地再上电**：所有模块必须共地，否则信号乱跳。
2. **电机电源与逻辑电源分开**：电机启动瞬间会把 5V 拉崩，导致 MCU 复位。
3. **示波器比打印好用**：时序问题靠 `printf` 永远查不出来。
4. **不要用 `HAL_Delay` 做控制**：阻塞式延时毁掉实时性。
5. **PID 采样周期固定**：周期抖动会让微分项爆炸。
6. **CAN 终端电阻**：两端各 120Ω，少了通信不稳。
7. **买两块板子**：烧坏一块还有备份，学习心情很重要。
