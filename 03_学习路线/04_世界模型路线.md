# 世界模型方向学习路线（分阶段）

目标：毕业时完成一个可写进论文的世界模型复现 + 小改进，具备读博或研究院岗位竞争力。

前提：这条路线的数学门槛最高，**不建议与另两条路线并行**。

---

## 阶段 1：数学地基（8–10 周）

### 学什么
| 内容 | 资源 | 重点 |
|---|---|---|
| 线性代数 | MIT 18.06 | SVD、特征分解、矩阵微分 |
| 概率论 | MIT 6.041 / Blitzstein | 贝叶斯、条件期望、高斯分布 |
| 概率图模型 | Stanford CS228 前 6 讲 | 变分推断、ELBO |
| 凸优化 | Stanford EE364a 前 8 讲 | 拉格朗日、KKT、对偶 |
| 数值方法 | 按需 | 数值积分、ODE 求解 |

### 验收
- 能推导 VAE 的 ELBO
- 能写出一个二次规划的 KKT 条件
- 能手推高斯分布的 KL 散度

> 这一步不能跳。Dreamer 的损失函数就是 ELBO 的变体，看不懂 ELBO 就看不懂 Dreamer。

---

## 阶段 2：深度学习与生成模型（10–12 周）

### 学什么
| 内容 | 资源 |
|---|---|
| 深度学习基础 | EECS498 或《Deep Learning》前 8 章 |
| VAE / GAN | 原论文 + 手写实现 |
| 扩散模型 | DDPM 论文 + `denoising_diffusion_pytorch` 代码 |
| Transformer / DiT | Attention 论文 + DiT 论文 |
| 3D 表示 | NeRF、3DGS 论文 + nerfstudio/gsplat |

### 项目
1. 手写 VAE，在 MNIST 上生成
2. 手写 DDPM，在 CIFAR-10 或 CelebA 上训一个
3. 用 3DGS 从一段手机视频重建桌面场景

### 验收
- 能解释扩散模型的前向/反向过程与损失
- 能说清 NeRF 与 3DGS 的表示差异与优劣

---

## 阶段 3：强化学习与最优控制（10–12 周）

### 学什么
| 内容 | 资源 |
|---|---|
| MDP、值迭代、策略梯度 | Sutton & Barto 前 8 章 |
| PPO / SAC | CS285 + 官方实现 |
| Model-based RL | CS285 后半 + Dreamer 论文 |
| 最优控制 | MIT Underactuated 前 8 讲、LQR、MPC、iLQR |

### 项目
1. 在 MuJoCo 里用 PPO 训一个 HalfCheetah
2. 实现一个 LQR 控制器并在倒立摆上验证
3. 读 DreamerV3，画出其架构图与损失组成

### 验收
- 能说清 model-free 与 model-based 的样本效率差异
- 能写出 LQR 的 Riccati 方程

---

## 阶段 4：世界模型精读（8–10 周）

### 学什么（按顺序）
1. *World Models* (2018)：理解 VAE + RNN + Controller 三件套
2. *Dreamer V1/V2/V3*：理解 RSSM、latent imagination、KL balancing
3. *MuZero*：理解 MCTS + learned model
4. *TD-MPC2*：理解 latent planning + MPC
5. *V-JEPA / V-JEPA 2*：理解表征空间预测
6. *Genie / Cosmos*：理解视频生成式世界模型

### 产出
- 一份 10 页的《世界模型技术路线对比》笔记（架构、损失、数据、算力、适用场景）

### 验收
- 能不看论文画出 DreamerV3 的计算图
- 能说清"为什么世界模型需要 latent 而不是像素"

---

## 阶段 5：复现（12–16 周）

### 按难度
1. **CartPole + Dreamer 简化版**（1–2 周，单卡）
2. **DeepMind Control Suite + DreamerV3**（3–4 周，单卡 12G 可跑）
3. **MuJoCo + TD-MPC2**（3–4 周）
4. **3DGS 场景重建 + 新视角渲染**（2 周）
5. **V-JEPA 2 零样本抓取**（4–6 周，需要机械臂）

### 验收
- 每个复现都要有：代码仓库、训练曲线、与原论文指标对比表、失败案例分析

---

## 阶段 6：小改进 + 论文（16–24 周）

### 选题方向（选一个）
| 方向 | 例子 |
|---|---|
| 表征改进 | 换编码器（ViT → 3DGS-aware）、加对比学习 |
| 动力学改进 | 引入物理先验、图结构、长期记忆 |
| 规划改进 | 改进 MPC 的采样策略、分层规划 |
| 数据效率 | 用预训练视觉骨干减少样本需求 |
| 机器人应用 | 用世界模型做抓取策略评估、sim-to-real |

### 交付
- 一篇 8–10 页论文（可以是硕士 dissertation）
- 代码开源 + 可复现脚本
- 一个 3 分钟讲解视频

| 1 数学 | 8–10 | 12 h |

| VAE/DDPM 小实验 | RTX 3060 6G | 云 GPU 按小时租 |

**现实建议**：硕士阶段不要碰视频生成式世界模型（算力不够），聚焦 latent dynamics + 3D 表征这两支。

---

## 避坑清单

1. **不要从视频生成入门**：算力门槛高、物理一致性差、和机器人脱节。
2. **不要跳过 RL 基础**：直接读 Dreamer 会看不懂 imagination rollout。
3. **不要只复现不分析**：面试/答辩会问"你的结果和论文差在哪、为什么"。
4. **不要忽视基线**：世界模型的对比基线是 model-free RL，必须跑。
5. **不要一个人硬扛**：找导师、找实验室集群、找同方向的同学。
6. **不要等到第二年才开始**：这条路线的周期最长，入学前就要启动。
