# 世界模型方向详解

## 1. 什么是世界模型

世界模型（World Model）= 一个能**预测"如果我做动作 A，世界接下来会变成什么样"**的内部模型。

它要回答三件事：
1. **状态表征**：把高维观测（图像/点云）压成低维状态
2. **动力学**：给定状态 + 动作，预测下一个状态
3. **奖励/价值**：预测这样做值不值得

有了它，机器人可以在"脑内"试错，而不必在真实世界反复试——这就是 model-based RL、规划、sim-to-real 的共同基础。

## 2. 四条技术流派（必须分清）

### 2.1 潜空间动力学（Latent Dynamics）
- **代表**：World Models (Ha & Schmidhuber, 2018)、Dreamer V1/V2/V3、MuZero、TD-MPC2
- **做法**：VAE/RNN 把观测编码成 latent，在 latent 空间学转移函数，用想象 rollout 训练策略
- **优点**：样本效率极高，适合机器人
- **缺点**：latent 不可解释，长时预测会漂移
- **入门代码**：DreamerV3 官方实现、TD-MPC2 官方实现

### 2.2 视频生成式（Video Generative）
- **代表**：Sora、GAIA-1、Genie、NVIDIA Cosmos、UniSim
- **做法**：用扩散/自回归模型直接生成未来视频帧，当作"神经仿真器"
- **优点**：可视、通用、能生成训练数据
- **缺点**：算力巨大、物理一致性差、实时性差
- **机器人用法**：生成合成数据、评估策略、做闭环仿真

### 2.3 3D 重建式（Geometric / Neural Rendering）
- **代表**：NeRF、3D Gaussian Splatting、Neural Scene Graphs、Point-Splatting
- **做法**：重建场景的显式/隐式 3D 表示，支持新视角合成与碰撞查询
- **优点**：几何准确、可用于导航与抓取
- **缺点**：动态场景难、需要多视角采集
- **机器人用法**：数字孪生、导航地图、抓取位姿评估

### 2.4 联合嵌入预测（JEPA 系）
- **代表**：I-JEPA、V-JEPA、V-JEPA 2、LeCun 的 world model 路线
- **做法**：在表征空间做预测，不重建像素
- **优点**：避开"生成细节"的浪费，适合规划
- **缺点**：较新，工程实践少
- **机器人用法**：V-JEPA 2 已展示零样本抓取与规划

## 3. 与机器人结合的三条落地路径

| 路径 | 做法 | 代表工作 |
|---|---|---|
| **Model-based RL** | 在世界模型里 rollout 训练策略，再迁到真机 | DreamerV3、TD-MPC2 |
| **策略评估与数据增强** | 用生成模型造数据/评估策略，减少真机成本 | UniSim、Cosmos |
| **神经仿真 + 规划** | 用 3D 重建/视频模型做 MPC 的预测器 | V-JEPA 2、Genie |

---

## 4. 知识栈（这是三条路线里数学最重的）

```
第 1 层：线性代数（SVD、特征分解）+ 概率论（贝叶斯、KL、ELBO）
第 2 层：深度学习（CNN、Transformer、VAE、GAN）
第 3 层：生成模型（扩散模型、自回归、flow matching）
第 4 层：强化学习（MDP、policy gradient、actor-critic、model-based RL）
第 5 层：最优控制（LQR、MPC、iLQR）
第 6 层：3D 视觉（多视图几何、NeRF、3DGS）
第 7 层：世界模型论文精读 + 复现
```

**数学警告**：如果你没学过概率图模型和变分推断，Dreamer 系列的 ELBO 推导会卡住。建议先用 2 周补 Bishop《PRML》第 1、9、10 章，或 Stanford CS228。

## 8. 常见误区

| 误区 | 现实 |
|---|---|
| "世界模型 = 视频生成" | 视频生成只是其中一支，且物理一致性最差 |
| "只要模型够大就能预测未来" | 长时预测误差累积是本质问题，不是规模问题 |
| "不需要机器人也能做" | 最终要落到 action 和 control，纯视频模型无法闭环 |
| "复现论文就是改个超参" | 大部分失败在数据管线、环境版本、随机种子 |
| "硕士一年能做出新方法" | 现实目标：扎实复现 + 一个小改进 |
