# AI 方向详解（机器人 / 具身智能）

## 1. 这个方向到底在做什么

不是"训练一个大模型"，而是解决三个子问题：

1. **感知**：从相机/激光/触觉信号里提取可用的状态（物体在哪、姿态如何、场景结构）。
2. **决策**：根据状态决定动作（抓哪里、怎么走、用多大力）。
3. **泛化**：换一个物体、换一个场景，还能不能用。

传统机器人用"建模 + 规划 + 控制"解决，AI 方向用"数据 + 学习"解决。硕士阶段你至少要能独立完成"数据采集 → 训练 → 真机部署"的闭环。

## 2. 细分赛道（按就业热度排序）

### 2.1 具身智能 / VLA（Vision-Language-Action）
- **是什么**：把视觉 + 语言指令直接映射成机器人动作序列。
- **代表工作**：RT-2、OpenVLA、π0（pi-zero）、NVIDIA GR00T N1、Diffusion Policy、ACT（ALOHA）。
- **技能**：Transformer、扩散模型、模仿学习、大规模数据管线、真机部署。
- **门槛**：高，但岗位最多、薪资最高。

### 2.2 机器人感知 / 3D 视觉
- **是什么**：检测、分割、6D 位姿估计、点云处理、SLAM。
- **代表工作**：ORB-SLAM3、FAST-LIO2、SAM、Grounded-SAM、AnyGrasp。
- **技能**：多视图几何、点云库（Open3D/PCL）、C++ 工程能力。
- **门槛**：中高，工业界需求稳定（自动驾驶、仓储、检测）。

### 2.3 强化学习 / 运动控制
- **是什么**：让四足、机械臂、无人机在仿真里学会运动技能，再迁移到真机。
- **代表工作**：Isaac Lab + legged_gym、ANYmal 系列、OpenAI Rubik's cube。
- **技能**：PPO/SAC、域随机化、sim-to-real、并行仿真。
- **门槛**：中高，需要 GPU 和仿真环境。

### 2.4 机器人 + 大模型 Agent
- **是什么**：用 LLM 做任务分解与工具调用，底层调用技能库。
- **代表工作**：SayCan、Code as Policies、VoxPoser。
- **技能**：Prompt 工程、Agent 框架、MCP 协议、任务规划。
- **门槛**：中低，最容易上手，但天花板依赖底层技能。

### 2.5 数据与仿真基础设施
- **是什么**：造数据、造仿真环境、做评测。
- **代表工作**：Open X-Embodiment、DROID、ManiSkill、RoboCasa。
- **技能**：仿真器二次开发、数据格式、分布式训练。
- **门槛**：中，岗位少但不可替代。

## 3. 知识栈（按学习顺序）

```
第 1 层：Python + NumPy + Linux + Git
第 2 层：线性代数 + 概率统计 + 微积分
第 3 层：PyTorch + 深度学习（CNN / Transformer）
第 4 层：计算机视觉（检测 / 分割 / 位姿）
第 5 层：机器人学基础（变换、运动学、ROS 2）
第 6 层：模仿学习 / 强化学习
第 7 层：VLA / 扩散策略 / 大模型 Agent
第 8 层：真机部署 + 数据闭环
```

**关键提醒**：第 5 层不能跳。很多纯 AI 背景的人做具身智能失败，是因为不懂坐标系、不懂关节限位、不懂控制频率。

## 5. 必做项目（按难度递增）

1. **CIFAR-10 手写 ResNet**（复习基础，1 周）
2. **YOLO 检测 + ROS 2 话题发布**（2 周）
3. **6D 位姿估计**（用 FoundationPose 或 AnyGrasp，3 周）
4. **ACT / Diffusion Policy 抓取**（用 SO-100 机械臂 + LeRobot，4–6 周）
5. **VLA 微调**（OpenVLA 或 π0 在小数据集上微调，6–8 周）
6. **Isaac Lab 训练四足行走 + sim-to-real**（8–12 周）

做到第 4 个就足够找到具身智能实习；做到第 5/6 个可以冲正式岗。

## 6. 常见误区

| 误区 | 现实 |
|---|---|
| "学会 PyTorch 就能做具身智能" | 还需要机器人学、控制、真机调试 |
| "仿真里成功 = 真机能用" | sim-to-real gap 通常需要域随机化 + 真实微调 |
| "模型越大越好" | 真机上 10 Hz 的控制频率下，小模型 + 好数据往往更实用 |
| "只做算法不碰硬件" | 具身智能岗位面试必问真机部署细节 |
| "论文没复现也能写简历" | 面试官会问 loss 曲线和失败案例 |

## 7. 就业去向

- **具身智能公司**：Physical Intelligence、Figure、1X、宇树、智元、银河通用、星海图
- **大厂研究院**：NVIDIA GEAR、Google DeepMind、Meta FAIR、字节 Seed、阿里达摩院
- **自动驾驶**：感知、预测、规划岗
- **工业视觉**：缺陷检测、3D 引导抓取
- **新加坡本地**：相对少，更多是智能制造、物流自动化、医疗影像

## 8. 一句话建议

**AI 方向的核心竞争力不是"会用框架"，而是"能在真机上把模型跑起来并持续改进"。** 所以无论如何要有一台自己的机械臂或小车。
