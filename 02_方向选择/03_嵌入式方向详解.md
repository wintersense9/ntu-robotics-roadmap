# 嵌入式方向详解（从 MCU 到 ROS 2）

## 1. 这个方向到底在做什么

嵌入式是机器人的"小脑和脊髓"：负责把上层算法发出的指令变成精确的电压、电流、时序，并把传感器信号可靠地送回去。核心指标只有四个：

- **实时性**：控制环路能不能稳定在 1 kHz
- **确定性**：同样的输入是否产生同样的输出
- **可靠性**：跑 72 小时会不会死机
- **成本/功耗**：量产时每块板子省几块钱

---

## 2. 完整技术栈（六层）

```
第 6 层：系统集成  ROS 2 / micro-ROS / EtherCAT 主站 / 多机通信
第 5 层：电机控制  FOC / 电流环-速度环-位置环 / 力控 / 伺服驱动
第 4 层：实时系统  FreeRTOS / Zephyr / 中断优先级 / 任务调度
第 3 层：总线与外设  CAN / UART / SPI / I2C / 定时器 / ADC / DMA / PWM
第 2 层：MCU 编程  STM32 HAL/LL / ESP-IDF / 寄存器级理解
第 1 层：C/C++ + 电路基础  指针、内存、结构体、模电数电、焊接、示波器
```

**学习原则**：从下往上，每层都要有实物验证。跳层学习（比如直接学 ROS 2 不碰 MCU）会导致"会调包但不知道为什么"。

---

## 3. 每层要掌握什么

### 第 1 层：C/C++ 与电路
- C：指针、结构体、位操作、`volatile`、中断上下文
- C++：类、引用、模板基础、RAII（现代 C++ 课里学）
- 电路：欧姆定律、分压、上拉/下拉、去耦电容、共地、电平匹配（3.3V vs 5V）
- 工具：万用表、电烙铁、示波器（或至少逻辑分析仪）

### 第 2 层：MCU 编程
以 STM32F4 为例，必须手写过：
- GPIO 输入输出、按键消抖
- 定时器：PWM 输出、输入捕获测编码器
- 串口：DMA + 空闲中断收不定长数据
- ADC：多通道扫描 + DMA
- 中断：NVIC 优先级、抢占与子优先级

### 第 3 层：总线与外设
| 总线 | 典型用途 | 要点 |
|---|---|---|
| UART | 调试、舵机、GPS | 波特率、校验、DMA |
| SPI | IMU、编码器、Flash | 时钟极性/相位、片选 |
| I2C | 传感器、EEPROM | 上拉电阻、总线锁死恢复 |
| CAN | 电机、汽车、多机 | 仲裁、过滤器、波特率 |
| EtherCAT | 工业伺服 | 从站芯片、分布式时钟（进阶） |

### 第 4 层：RTOS
- 任务、优先级、栈大小
- 信号量、队列、互斥锁
- 优先级反转、看门狗
- 推荐：FreeRTOS（资料最多），Zephyr（更现代）

### 第 5 层：电机控制
- 直流有刷：PWM + 编码器 + PID
- 无刷（BLDC/PMSM）：六步换相 → FOC（Clarke/Park 变换、SVPWM、电流环）
- 舵机：位置控制、总线舵机协议（Dynamixel Protocol 2.0）
- 力控：电流 → 力矩估算、阻抗控制
- 开源参考：SimpleFOC、ODrive、Moteus

### 第 6 层：系统集成
- ROS 2 节点、话题、服务、Action
- micro-ROS：把 MCU 接入 ROS 2 图
- 通信频率设计：感知 30 Hz、规划 10 Hz、控制 1 kHz
- 时间同步：PTP / 硬件触发

## 5. 学习路径（与硬件同步）

```
月 1：C 语言 + 一块 STM32 开发板，点亮 LED、按键、串口打印
月 2：定时器 PWM + 编码器 + 直流电机 PID 调速
月 3：IMU（SPI）+ 姿态解算 + 串口上位机可视化
月 4：FreeRTOS 重构上面的代码，多任务 + 队列
月 5：CAN 总线 + 总线舵机/驱动器，做一个小型机械臂
月 6：树莓派 + ROS 2，用 micro-ROS 把 MCU 接进来
月 7–8：完整项目（移动抓取平台或四足/云台）
```

## 6. 常见误区

| 误区 | 现实 |
|---|---|
| "先学 ROS 2，硬件以后再说" | 不会 MCU 的 ROS 工程师只能做上层，做不了机器人本体 |
| "用 Arduino 库就够了" | Arduino 隐藏了定时器和中断，学不到实时控制 |
| "PID 调参靠试" | 要先懂系统辨识和采样周期，否则永远调不好 |
| "仿真能跑就行" | 电机干扰、电源跌落、通信丢包只有真机会暴露 |
| "买最贵的板子" | 入门用 50 元的板子学原理，进阶再上 Jetson |

## 7. 就业去向

- **机器人本体公司**：宇树、智元、优必选、大疆、节卡、遨博
- **汽车**：域控制器、线控底盘、BMS
- **消费电子**：扫地机、无人机、影像设备
- **工业自动化**：伺服驱动、PLC、运动控制卡
- **新加坡**：精密制造、半导体设备、物流自动化、医疗设备

嵌入式岗位供需比明显好于纯算法岗，且不容易被 AI 替代——因为需要和物理世界打交道。

## 8. 一句话建议

**嵌入式的护城河是"能把东西做出来并稳定运行"。** 简历上写"独立完成 1 kHz 电流环 + ROS 2 集成"，比写十个课程项目都管用。
