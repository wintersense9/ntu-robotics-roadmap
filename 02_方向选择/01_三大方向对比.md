# 三大方向对比与选择

## 1. 一张表看清差别

| 维度 | AI 方向 | 嵌入式方向 | 世界模型方向 |
|---|---|---|---|
| **一句话** | 教机器人看懂并学会做事 | 让机器人动得准、通信稳、跑得久 | 让机器人在脑中预演未来 |
| **典型日常** | 做数据、训模型、调超参、做评测 | 接线、烧固件、调环路、查时序 | 读论文、复现模型、跑大规模实验 |
| **核心技能** | Python/PyTorch、CV、RL、VLA | C/C++、RTOS、总线、电机控制 | 生成模型、RL、3D 表征、概率 |
| **数学** | 线代、概率、优化（中高） | 信号与系统、控制、离散（中） | 概率、优化、生成模型（高） |
| **硬件依赖** | 低，仿真可替代 | 高，必须真机 | 中，主要吃 GPU |
| **调试方式** | 看 loss、看指标、看可视化 | 示波器、逻辑分析仪、串口打印 | 看 loss、看 rollout 视频 |
| **反馈周期** | 几小时到几天 | 几秒到几分钟 | 几天到几周 |
| **失败成本** | 低（重跑） | 中（可能炸板） | 低（烧钱烧时间） |
| **NTU 课程覆盖** | ★★★☆ | ★★★★★ | ★★ |
| **自学占比** | 60% | 40% | 75% |
| **就业岗位数** | 多（但竞争激烈） | 多（供给少，好就业） | 少（高门槛研究岗） |
| **起薪天花板** | 高 | 中高 | 很高 |
| **适合性格** | 喜欢抽象、能忍受不确定性 | 喜欢确定性、享受"物理世界被修好" | 喜欢读论文、能长期没有正反馈 |

## 2. 三个方向的"能力金字塔"

### AI 方向
```
        ┌─ VLA / 具身智能（前沿）
        ├─ 强化学习 / 模仿学习
        ├─ 3D 视觉 / SLAM
        ├─ 深度学习基础（CNN / Transformer）
        └─ Python + 数学 + Linux
```

### 嵌入式方向
```
        ┌─ 系统集成（ROS 2 + 实时通信）
        ├─ 电机控制（FOC / 伺服 / 力控）
        ├─ RTOS + 总线（CAN / EtherCAT / SPI）
        ├─ MCU 外设（定时器 / ADC / PWM / DMA）
        └─ C/C++ + 电路基础 + 焊接调试
```

### 世界模型方向
```
        ┌─ 机器人应用（规划 / 策略评估 / 数据生成）
        ├─ 世界模型（Dreamer / TD-MPC / 视频生成）
        ├─ 生成模型（扩散 / 自回归 / 3DGS）
        ├─ 强化学习 + 最优控制
        └─ 概率 + 凸优化 + 深度学习
```

## 3. 自测题（每题 1 分，选"是"）

**偏 AI：**
1. 你写 Python 比写 C 舒服。
2. 你能接受花两周调一个模型但结果是"没提升"。
3. 你看到一篇新论文会想"我能不能复现"。
4. 你对"数据"的耐心大于对"电路"的耐心。

**偏嵌入式：**
1. 你喜欢东西"能摸到、会动"。
2. 你愿意为一个小 bug 查三小时时序图。
3. 你对"实时性、功耗、成本"敏感。
4. 你觉得让一个电机平稳转起来很有成就感。

**偏世界模型：**
1. 你能连续读 5 篇 20 页的论文不烦。
2. 你对"预测未来"这件事本身着迷。
3. 你数学不排斥，甚至喜欢推导。
4. 你能接受半年没有可演示的成果。

> 得分最高的方向作为主路线，第二高的作为"辅助技能"。不要三个都做。

## 4. 组合策略（比单选更现实）

| 组合 | 适合谁 | 典型岗位 |
|---|---|---|
| AI 主 + 嵌入式辅 | 想做具身智能但要有真机能力 | 具身智能算法工程师、机器人感知 |
| 嵌入式主 + AI 辅 | 想做机器人本体公司 | 机器人系统工程师、固件负责人 |
| 世界模型主 + AI 辅 | 想读博 / 进研究院 | 研究科学家、仿真算法 |
| 世界模型主 + 嵌入式辅 | 想做 sim-to-real | 自动驾驶仿真、训练数据平台 |

**最不推荐**：三个方向平均用力。硕士 1–1.5 年，平均用力等于三个都半桶水。

## 5. 按你现有背景的建议

如果你已有：Python、PyTorch（ResNet 迁移学习）、LLM/Ollama 调用、FastAPI、多智能体系统经验，那么：

- 走 **AI 方向**迁移成本最低，已有能力直接复用；
- 走 **世界模型方向**需要补数学（概率 + 优化）和生成模型，但 LLM/Agent 经验对"世界模型 + 规划"有帮助；
- 走 **嵌入式方向**是从零开始，但就业最稳，且 NTU 课程帮你补理论。

**一个务实的组合**：AI 为主路线（复用已有能力），嵌入式为辅助（用 3000 元档硬件做 2 个真机项目）。这样毕业时既有算法作品，又有真机经验，在具身智能岗位上有明显优势。

---

## 6. 就业市场观察（2026）

- **具身智能**是当前最热赛道，中国（宇树、智元、银河通用、优必选）与北美（Figure、Tesla Optimus、Physical Intelligence）都在抢人，但要求"算法 + 真机"双能力。
- **嵌入式/固件**长期缺人，尤其是懂 FOC、EtherCAT、功能安全的工程师，薪资不如纯算法但稳定性高。
- **世界模型**岗位集中在少数大厂研究院与自动驾驶公司，博士优先，硕士需要强论文或强工程复现能力。
- **新加坡本地**：精密制造、半导体设备、医疗机器人、物流自动化是主要去向，纯 AI 岗少于中美。
